# 系統參數

系統參數頁集中存放「依現場實測需要調整」的系統上限與門檻。修改後按 **儲存**，下一次操作即生效，**不需重啟任何服務**。

## 進入頁面

選單：**工程師模式 → 系統參數**

只有 Engineer 可進入。頁面依群組列出參數，每個參數顯示說明、允許範圍與預設值；頁尾顯示 **最後更新** 時間（從未修改過則顯示「尚未自訂（使用預設值）」）。

## 參數一覽

| 參數 | 預設 | 範圍 | 影響 |
|------|------|------|------|
| **每點位最多筆數** | 5,000 筆 | 100 ～ 100,000 | 歷史趨勢查詢與匯出共用；超過時只取前 N 筆，並提示使用者縮短區間或加大間隔 |
| **匯出儲存格上限** | 50,000 格 | 1,000 ～ 1,000,000 | 歷史趨勢匯出前預估「點位數 × 預估筆數」，超過即擋下（不查資料庫），避免伺服器記憶體不足 |
| **累計值抖動容差** | 1 % | 0 ～ 50 | 累計值（kWh、m³…）下降幅度在「前值 × 容差%」以內視為讀值抖動；超過才判定為歸零 / 換表並分段計算差異值 |

## 操作步驟

1. 修改欲調整的欄位
2. 按 **儲存**，出現「已儲存」即生效
3. 要回到出廠設定時，按 **填入預設值** 後再按 **儲存**

輸入超出範圍時會提示「數值無效或超出範圍」，不會存檔。

## 調整建議

### 每點位最多筆數

- 使用者常抱怨「查一個月只看到前幾天」→ 可適度調高
- 伺服器記憶體小、或趨勢頁載入很慢 → 維持預設或調低
- 1 分鐘資料一個月約 43,200 筆；要完整看一個月的分鐘資料需調到 50,000 左右

### 匯出儲存格上限

- 匯出 Excel 時被擋下，且伺服器資源充裕 → 可調高
- 調高前請確認伺服器記憶體；大量匯出會佔用 Web 服務記憶體

### 累計值抖動容差

- 電表讀值偶爾小幅倒退，被系統誤判為「換表」導致差異值異常 → 調高容差
- 現場真的換表或歸零，但系統沒判斷出來 → 調低容差

> ⚠️ 注意：容差影響所有累計值差異計算。調整後請到歷史趨勢以「差異值」檢視幾個代表性電表 / 水表，確認結果合理。

## 技術說明

- 參數存放在資料庫 `SystemSettings` 表，鍵值 `system_parameters`（整份 JSON）
- 資料庫中沒有值、內容損毀或讀取失敗時，一律採用預設值並記錄於 Web log，不會擋住使用者功能
- 升級新增參數時會自動補上預設值，不需手動遷移
