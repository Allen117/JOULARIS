# OPC UA 來源

Engine 可作為 OPC UA Client，週期讀取外部 OPC UA Server 的節點，匯入與 Modbus 相同的歷史、即時值、警報與計算流程；設定為可控的點位（AO / DO）也能從監控畫面寫回。與 Modbus / DB 來源最大的差異是：**所有欄位都能直接在網頁上新增、修改、刪除，免重啟 Engine**。

## 基本觀念

- **一份設定檔 = 一台 OPC UA Server**，存放在 `C:\JOULARIS\Engine\App\OpcUaPoint\{名稱}.json`，內含多個「設備」分組
- **SID 格式 `OPC{編號}-S{Seq}`**，例 `OPC1-S5`。Seq 由系統配號並記在設定檔內，**刪除不回收、插入不位移**，所以 OPC UA 點位可以自由增刪排序，不會像 Modbus 那樣 SID 錯位
- **Server 名稱建立後不可更改**（改名會產生新編號，所有 SID 跟著變）
- 點位數不設上限，Engine 會依 Server 能力分批讀取

> ⚠️ 注意：目前只支援 SecurityPolicy **None**（不加密），可搭配帳號密碼或匿名登入；Server 憑證一律接受。帳密以明文存放於設定檔。請只在可信任的內網使用。

## 進入頁面

選單：**工程師模式 → 點位設定 → OPC UA 來源**

- **頁首**：**新增 Server**，以及 Excel 工具列（**下載範本** / **匯出 Excel** / **匯入 Excel**）
- **左側「Server 清單」**
- **右側「連線設定」卡**與**「點位設定」卡**

## 新增 Server

1. 按 **新增 Server**
2. 在 **連線設定** 填寫：

| 欄位 | 說明 |
|------|------|
| **名稱** | 僅限英數、`_`、`-`，建立後不可更改 |
| **Endpoint URL** | 以 `opc.tcp://` 開頭，例 `opc.tcp://192.168.1.10:4840` |
| **帳號** / **密碼** | 帳號留空 = 匿名登入；已設定密碼時欄位留空代表不變更 |
| **掃描週期 (ms)** | 讀取週期，最短 200 |
| **逾時 (ms)** | 連線 / 讀寫逾時，最短 1000 |
| **啟用監控** | 取消勾選即暫停此 Server 的採集 |

3. 按 **儲存連線設定**

## 建立點位

1. 在 **點位設定** 按 **新增設備**，輸入 **設備名稱**（例如 `CH1`）
2. 在該設備下按 **新增點位**，填寫：

| 欄位 | 說明 |
|------|------|
| **名稱** | 點位名稱 |
| **TagName (NodeId)** | 完整 NodeId，例 `ns=2;s=D1.T` 或 `ns=3;i=1234` |
| **控制類型** | **唯讀** / `AO`（類比寫入）/ `DO`（數位寫入 0/1） |
| **倍數** | 工程值 = 原始值 × 倍數；寫回時會反算（輸入值 ÷ 倍數），不可為 0 |
| **單位** / **Min** / **Max** | Min、Max 選填，兩者都填時 Min 必須小於 Max |

3. 對有疑問的 NodeId 按 **測試讀取**：系統用表單目前的連線資訊實際連一次，回報原始值與換算後的工程值（不會存檔）
4. 按 **儲存點位**

存檔後系統自動：回寫設定檔、更新資料庫、通知 Engine 重載（MQTT `SCADA/Sys/OpcUaCoordinator/Reload`），新點位立即出現在即時數據頁。

> 💡 提示：OPC UA 點位在即時數據、警報設定、計算點位、歷史趨勢、條件控制與畫面設計中都與 Modbus 點位同等可用；畫面設計的點位選擇器中以 `{Server}/{設備}` 分群。

## 用 Excel 批次維護

點位很多時可用 Excel：

1. **下載範本** 取得 `OPCUA範本.xlsx`，或先 **匯出 Excel** 取得現行設定
2. **一張工作表 = 一台 Server**（工作表名稱即 Server 名稱，1～50 字，英數、`_`、`-`）
3. 第 1 列為連線參數：`EndpointUrl`、`Username`、`Password`、`ConnectTimeout`（空白 5000）、`PollingInterval`（空白 1000）、`MonitorEnabled`（空白 TRUE）、`MaxNodesPerRead`（空白 0 = 依 Server 能力）
4. 第 3 列起：**Name / TagName / ControlType / Ratio / Unit / Min / Max / Device / Seq**
5. **Device** 留空時，系統從 NodeId 推得（`ns=2;s=D1.T` → `D1`）
6. **Seq（灰底）不要改**；新增的點位 Seq 留空，系統自動配號
7. 回網頁 **匯入 Excel**，檢視預覽後 **確認匯入**

OPC UA 匯入的特別規則：

- 點位**以 Seq 比對，不以位置比對**——刪中間的列、調換順序、插入新列，既有點位的 SID 都不變，因此沒有「SID 位移」警告
- Excel 少了的既有點位會在預覽顯示「將移除 N 個點位」
- **匯出不含密碼**；匯入時密碼欄空白 = 保留原密碼
- 匯入**不會刪除 Server**（Excel 少了某張工作表不會刪它），刪除請用頁面上的 **刪除 Server**
- 匯出到來源資料夾、從資料夾匯入、覆寫網頁修改警告等規則與 [Modbus 來源](modbus-source) 相同；全部匯出的檔名為 `OPCUA設定.xlsx`

> ⚠️ 注意：若在 Excel 把某列的 Seq 改成另一個既有的 Seq，兩個點位會互換身分（歷史與綁定跟著錯）。預覽中該 Seq 的名稱 / NodeId 會顯示變更，請仔細核對。

## 刪除

- **刪除設備**：在點位設定中刪除該設備與其所有點位，按 **儲存點位** 生效
- **刪除 Server**：按 **刪除 Server** 並確認，會刪除設定檔與資料庫中的點位設定；**歷史資料保留**

> ⚠️ 注意：OPC UA 的刪除是真的刪除設定（不像 Modbus / DB 會移到 `_deleted` 備份）。刪除前建議先 **匯出 Excel** 留底。

## 控制寫回

畫面上 AO / DO 元件綁定控制類型為 AO / DO 的 OPC UA 點位後即可操作：

- **AO**：寫入原始值 = 輸入值 ÷ 倍數，並自動轉成 Server 端該節點的資料型別
- **DO**：值大於 0.5 寫 true，否則 false
- 控制類型為唯讀的點位會被拒絕寫入；Server 未連線時寫入失敗並記錄於 Engine log

## 常見狀況

| 狀況 | 原因 / 處理 |
|------|------------|
| 點位全部 Bad | 連不上 Server：檢查 Endpoint URL、防火牆、帳密；用 **測試讀取** 驗證 |
| 單一點位 Bad | NodeId 錯誤或該節點非數值型別（字串 / 陣列不支援） |
| 寫入失敗 | 點位控制類型為唯讀，或 Server 端節點不可寫 |
| 刪除點位後即時數據頁短暫又出現 | MQTT broker 上的舊保留訊息，屬正常；Engine 與 broker 全部重啟可清除 |
| 授權失效時 OPC UA 也停了 | 正常：授權失效時 Modbus、DB、OPC UA 採集一律暫停，見 [授權加密狗](license) |
