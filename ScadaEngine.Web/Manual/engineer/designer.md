# 畫面設計

畫面設計用來建立「即時監控」的各個監控頁：放上背景圖（系統圖、平面圖），拖曳元件到畫布並綁定點位。儲存後，操作人員在 **即時監控** 看到的就是這裡設計的頁面。

## 基本觀念

- **頁面樹**：頁面可以有子頁面，形成多層樹；**第一個根頁面就是即時監控的預設首頁**
- **元件綁定兩種點**：顯示用的元件綁 **SID**（讀值）；控制用的元件綁 **CID**（寫值）
- **儲存 = 發布**：按 **儲存** 會把所有頁面整包寫入資料庫，即時監控隨即讀到新版本；沒按儲存就離開，變更不會保留
- **權限**：User 角色能看哪些監控頁、能否操作控制，在 **系統設定 → 帳號管理** 的 **即時監控子頁面（ScadaPage）** 逐頁設定，見 [角色體系與帳號 SOP](roles-accounts)

> ⚠️ 注意：不要同時在兩個瀏覽器分頁編輯畫面設計。儲存是整包覆寫，後存的會蓋掉先存的。

## 進入頁面

選單：**工程師模式 → 畫面設計**

畫面由左到右為：

- **頁面** 面板：頁面樹，右上 + 號 **新增根頁面**
- **元件庫**：分 **顯示元件**、**點位與控制**、**設備與動畫** 三類，可收合
- **畫布**：上方工具列有 **清除**、**匯入圖片**、**移除背景圖**、對齊與等距分布按鈕、**儲存**
- **屬性** 面板：點選元件後在此編輯

## 元件一覽

| 分類 | 元件 | 用途 |
|------|------|------|
| 顯示元件 | **表格** | 多列多欄的數據表，每一格可獨立綁點位 |
| 顯示元件 | **儀錶板** | 半圓儀錶，依量程與上下限變色 |
| 顯示元件 | **即時曲線** | 綁一個點位，顯示近 N 分鐘滾動趨勢 |
| 顯示元件 | **文字** | 純文字標籤 |
| 點位與控制 | **控制按鈕** | 綁 CID，按下寫入固定 **控制值** |
| 點位與控制 | **AI 點位** | 顯示類比值；可切換即時值 / 當日累積 / 當月累積 |
| 點位與控制 | **DI 點位** | 開關狀態燈號或文字 |
| 點位與控制 | **AO 點位** | 類比輸出設定值（手動 / 自動控制選單） |
| 點位與控制 | **DO 點位** | ON / OFF 切換（手動 ON / 手動 OFF / 自動控制） |
| 設備與動畫 | **水泵**、**冷卻水塔**、**空調箱風扇**、**冰機** | 多槽位設備元件：運轉、故障、手自動、頻率、負載、啟停、頻率設定、溫度設定等 |
| 設備與動畫 | **管路** | 可折彎的管線，依 DI 或類比量＋閾值決定是否流動 |
| 設備與動畫 | **圖片/動畫** | 自訂圖片或 GIF，可依點位狀態切換動畫圖與靜止圖 |

## 建立一個監控頁

### 步驟一：建立頁面與背景

1. 在 **頁面** 面板按 + 新增根頁面，或在既有頁面按右鍵 → **新增子頁面**
2. 右鍵 → **編輯** 可設定 **頁面名稱** 與 **頁面圖示**
3. 工具列按 **匯入圖片**，選系統圖或平面圖作為畫布背景

### 步驟二：放置元件

1. 從 **元件庫** 拖曳元件到畫布
2. 拖曳元件移動位置、拖曳右下角縮放；按 Del 鍵刪除
3. 按住 Ctrl 或 Shift 可多選，再用工具列 **靠左**、**靠上**、**水平置中**、**水平等距分布** 等對齊
4. 畫布上 Ctrl+C / Ctrl+V 複製元件（**會保留原本的點位綁定**）

### 步驟三：綁定點位

1. 點選元件，在 **屬性** 面板按 **綁定**（已綁定的按 **重選**、**清除**）
2. 點位選擇器依序選 **選擇點位來源** → **選擇設備** → **選擇點位**，按 **確認**
3. 單位、量程等會自動從點位帶入，可再手動修改
4. 數值類元件的 **小數點位數** 也會依點位單位自動帶入（例如電壓、電流、功率、溫度 1 位，功因、頻率 2 位，轉速 0 位，判斷不出時 1 位）；表格只有在該欄還沒設定位數時才會自動帶入

> 💡 提示：手動改過 **小數點位數** 後，再按 **重選** 換點位，不會覆蓋你設定的位數。之前就已儲存的頁面不受影響，維持原本的 2 位；要套用新規則，請重選點位或手動修改。

點位來源包括：**設備點位**（Modbus，OPC UA 以 `{Server}/{設備}` 分群也在此列）、**計算點位**、**DB 來源點位**、**迴路**（能源迴路的本日 / 本月度數、電費、即時需量）、**需量點位**。部分元件（如 DI、接點類）另可切換 **排程** 為來源。

### 步驟四：儲存

按工具列 **儲存**，出現「已成功儲存至資料庫」即完成。到 **即時監控** 開啟該頁確認數值與動畫。

## 設備元件一次綁整台

水泵、冷卻水塔、空調箱風扇、冰機這類元件有多個槽位，逐一綁定很耗時。系統可以「選一台設備，自動帶入所有槽位」：

1. 從元件庫拖設備元件到畫布，點位選擇器標題顯示 **選擇設備**
2. 在設備清單點到最末層的設備（例如 Modbus 的子設備、多站號的某一站）
3. 畫面顯示 **槽位 → 命中點位** 預覽與「命中 N / M 個槽位」：每個槽位對到的點位名稱、**未找到**，或 **多筆命中（取第一筆）**
4. 按 **確認**，所有命中的槽位一次寫入；未命中的槽位之後在屬性面板逐一 **重選** 補綁
5. 已放好的元件可在屬性面板按 **重新指定設備**，整台換成另一台設備的點位

比對依據是點位名稱中的角色字樣（例如 RUN / 運轉、故障、手自動、頻率、啟停、頻率設定）。設備邊界來自 Modbus 的 **Device（子設備）** 欄，所以先在 [Modbus 來源](modbus-source) 把子設備填好，自動綁定的命中率最高。

> 💡 提示：關閉選擇器不確認，仍會建立未綁定的元件，不會卡住作業。

## 表格的快速帶入

表格每一格都能綁點位（右鍵 **綁定點位**）。表格首欄為設備名、表頭為角色（運轉、頻率…）時，綁定一格後系統會偵測同一設備的其他角色，跳出 **列範本建議**，可 **直接帶入**、**調整順序** 或 **不帶入**；表頭與迴路名稱相符時則跳出 **迴路自動帶入**，可勾選要帶入的指標欄。

## 複製整頁（新增同型設備）

現場新增第 3 台冰機時，版面跟前兩台幾乎一樣，只有點位不同：

1. 在頁面樹對來源頁按右鍵 → **複製此頁**
2. 在目標位置按右鍵 → **貼上為子頁面**，或在頁面樹空白處右鍵 → **貼上為根頁面**
3. 新頁名為「原名 - 複製」，**所有點位綁定已清空**，版面、顏色、尺寸、背景圖完全保留
4. 逐一重綁點位（設備元件用 **重新指定設備** 最快），按 **儲存**

> ⚠️ 注意：整頁複製只複製該頁，不含子頁。另外畫布上 Ctrl+C / Ctrl+V 複製元件會**保留**綁定，兩者語意相反，請勿混用。

> 💡 提示：背景圖太大時，複製會自動略過背景圖並提示，貼上後再重新 **匯入圖片** 即可。

## 匯入頁面檔

開發端可用系統圖工具產生 `.joularis-page.json` 頁面檔（底圖 + 已排好位置的設備點位元件），帶到現場匯入：

1. 頁面樹空白處或頁面節點右鍵 → **匯入頁面檔…**，選檔（上限 8 MB）
2. 對話框每台設備一列：**設備**、**型別**、**對應 Device**（系統依設備 ID 自動預選，對不到時標紅、請手動選）、**命中**
3. 可展開角色明細檢查；勾選 **保留未命中的座位（之後手動綁點）** 會建立所有元件
4. 按 **建立頁面**，再按 **儲存** 才寫入資料庫

## 頁面排序與首頁

頁面樹可拖曳搬移或調整順序；把某頁拖到根層第一個，它就成為即時監控的預設首頁（系統會提示首頁已變更）。按 **儲存** 後生效。

## 常見狀況

| 狀況 | 原因 / 處理 |
|------|------------|
| 元件顯示「未綁定 SID / 未綁定 CID」 | 尚未綁點，或整頁複製後綁定已清空 |
| 點位改名後畫面上的標題沒變 | 元件標題是綁定當下的副本，需重選點位或手動改標題 |
| 點位選擇器顯示「無法載入設備/點位清單」 | 資料庫連線問題，檢查 Web log |
| User 看不到新頁面 | 到帳號管理為該 User 勾選該頁的 **可檢視** |
| 管路永遠不流動 | 管路綁定為 DI 或類比二擇一；類比綁定需設 **閾值** 與 **流動條件** |
