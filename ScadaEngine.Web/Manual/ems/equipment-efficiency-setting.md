# 設備效率設定

這一頁用來建立冰機與空壓機的「設備清單」，並告訴系統每台設備的耗電、冷量、空氣量等各要讀哪一個點位。設定好後，[冰機 / 空壓機效率診斷](equipment-efficiency) 與 EMS 首頁的效率卡片才有資料。

## 如何進入

導覽列 **設備效率 → 設備效率設定**，或在效率診斷頁右上角點 **設備效率設定**。

頁面上方有 **冰機**、**空壓機** 兩個分頁，右上角有 **重新掃描**、**手動新增**、**回填全部** 三個按鈕。

## 每台設備需要哪些點位

| 設備 | 必要點位 | 選用點位 |
|------|---------|---------|
| 冰機 | 電力 kW **或** 電能 kWh（累積）擇一；冷量：**冰水流量 + 冰水出水溫 + 冰水回水溫** 三者齊全，或直接的 **冷量 RT** 點 | 冷卻水進 / 出水溫、蒸發 / 冷凝飽和溫度、負載率 %、運轉狀態 |
| 空壓機 | 電力 kW **或** 電能 kWh（累積）擇一；**空氣量（排氣量）** | 排氣壓力、排氣溫度、加載狀態、負載率 %、運轉狀態 |

> 💡 提示：冷量以「冰水流量 × 出回水溫差」計算最準確，變流量系統也適用；兩種方式都綁時以計算值為準。溫度只接受 °C。

## 方式一：自動掃描帶入

第一次進入某分頁且還沒有任何設備時，系統會自動掃描點位，若找到候選會彈出「掃描到 N 台疑似冰機，要帶入嗎？」。之後也可隨時按 **重新掃描**。

1. 系統依通訊設備分群與點位名稱，判定哪些群組像冰機或空壓機（水泵、冷卻水塔、流量計等輔機會自動排除）
2. 每台候選會列出：設備名稱（可改）、**判定依據**、**高信心** / **中信心** / **低信心**、各角色對應的點位與單位
3. 檢查每個角色的點位是否正確：
   - 下拉分為 **本設備** 與 **其他設備（符合此角色）** 兩段，例如流量計屬於另一個通訊設備時可從後者挑
   - 都找不到時按「⋯」**從其他設備挑選點位**
   - 標「N 筆命中」表示有多個點位符合，已先取第一筆，請確認
4. 缺必要點位的候選會顯示「缺：…」，補齊後才能勾選；同名或主要點位相同的會標 **已存在**、預設不勾
5. 勾選要帶入的設備（可按 **全選可帶入者**），按 **帶入勾選的 N 台**

> ⚠️ 注意：冰機帶入後預設門檻為「依標準、水冷 / 離心 / 定頻」，請逐台編輯，依實際機型與額定冷量修正，評級才會準確。

## 方式二：手動新增 / 編輯

1. 按 **手動新增**（或清單中某台的 **編輯**）
2. 填寫基本資料：

   | 欄位 | 說明 |
   |------|------|
   | **名稱**、**排序** | 顯示名稱與順序 |
   | **額定冷量（RT）** / **額定空氣量（m³/min）** | 銘牌額定產出 |
   | **額定電力（kW）** | 用於停機判定：低於額定 5% 視為停機 |
   | **kWh 累積點溢位上限** | 電能表累積值歸零前的最大值（選填） |
   | **「優」門檻** / **「可」門檻** | 評級分界 |
   | **比熱 kJ/(kg·K)（乙二醇系統）** | 冰機專用；一般冰水用預設值即可，乙二醇系統才需調整 |
   | **備註** | 選填 |

3. **冰機另有「機型與評級門檻」**：選 **冷卻方式**（水冷 / 氣冷）、**壓縮機形式**（離心 / 螺旋 / 渦卷 / 往復）、**定頻 / 變頻**、**門檻模式**
   - **依標準（ASHRAE 90.1）**：優 / 可門檻自動帶出並鎖定，畫面即時預覽「90.1 標準滿載值 … kW/RT → 優 ≤ …、可 ≤ …」
   - **手動**：自行輸入優 / 可門檻
4. **空壓機另有「空壓系統診斷（皆可不填）」**：**控制型式**、**VSD 最低負載（%）**、**銘牌最高工作壓力（bar）**、**每小時最多啟動次數**。未填時診斷會改用推定值並標示
5. 在 **角色點位** 區為各角色選點位與單位（單位會依點位自動猜測，認不得時請手動選）
6. 缺必要點位時會提示「尚缺必要點位：…」，**儲存** 按鈕無法按下
7. 按 **儲存**

> 💡 提示：空壓機的預設門檻 7 / 9 kW/(m³/min) 僅供起點，請依銘牌或驗收報告調整。

設備種類建立後不能更改（冰機改成空壓機會讓點位全部錯置），請刪除後重建。

## 設定什麼時候生效

存檔後**不需要重新啟動**，系統從下一個整點起依新設定統計每小時效率。

## 回填歷史

如果改了點位綁定或單位，想讓**過去**的累計效率也用新設定重算：

1. 在清單某台按 **回填歷史**（只重算這一台），或按右上 **回填全部**（冰機 + 空壓機全部）
2. 選 **起日** 與 **迄日（含）**，最多 366 天
3. 按 **開始回填**

系統會在背景逐小時重算，資料量大時需要數分鐘。

## 啟用、停用與刪除

- 清單的 **狀態** 欄顯示 **啟用** / **停用**，可在編輯視窗切換；暫時不想納入效率統計的設備可設為停用
- **刪除** 會連同該設備已累計的效率資料一併刪除，無法復原

## 常見狀況

| 狀況 | 原因與處理 |
|------|-----------|
| 掃描顯示「沒有掃描到疑似冰機的設備」 | 點位名稱或通訊設備分群不易辨識，請改用 **手動新增** |
| 同一個角色出現「N 筆命中」 | 該設備有多個名稱相似的點位，請手動確認選對的那一個 |
| 找不到流量計點位 | 流量計常屬於另一個通訊設備，請在下拉的「其他設備」段或用「⋯」挑選 |
| 溫度點是 °F | 系統只收 °C，請先建立換算用的計算點位 |
| 儲存後診斷頁沒有立刻有累計資料 | 每小時整點後幾分鐘才會統計上一小時；要看過去資料請使用回填歷史 |
