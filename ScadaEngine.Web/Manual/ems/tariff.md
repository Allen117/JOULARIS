# 費率設定（電 / 水 / 氣）

費率設定決定電費、水費、氣費怎麼計算。三種費率各有一頁：

| 設定頁 | 選單路徑 | 計價方式 |
|--------|----------|----------|
| **電費設定** | **能管設定 → 電表 → 電費設定** | 台電各類電價方案（累進 / 單一費率 / 時間電價），逐小時計價 |
| **水費設定** | **能管設定 → 自來水表 → 水費設定** | 台水流動水費分段累進 |
| **氣費設定** | **能管設定 → 氣表 → 氣費設定** | 依供氣合約自填分段累進 |

> ⚠️ 注意：三種費用都**只計算流動費用（依用量計價的部分）**，**不含基本費**（電費的契約容量基本電費、水費的口徑基本費等）。因此報表金額會比實際帳單少，請以「流動費用」解讀。

## 電費設定

### 畫面說明

<!-- IMG-TODO: ems/tariff-01 | 電費設定：頂部累計卡片、方案選擇、採用時間軸與方案編輯區 | route=/TariffSetting -->

- **頂部卡片**：**目前採用方案**、**目前累計用電度數**、**目前累計電費**（主要電表本期，不含基本電費）
- **電價方案選擇**：**用電類別**（表燈（住商）/ 低壓電力 / 高壓電力 / 特高壓電力 / 自訂）→ **電價方案**，以及 **設為採用方案**、**新增方案**、**複製方案**、**刪除方案** 按鈕
- **採用時間軸**：哪天起改用哪個方案
- **方案編輯區**：依方案型態顯示 **夏月期間**、**基本電費**、**流動電費時段** 或 **累進級距（流動電費）**、**每月總度數超額加價** 等
- **契約容量歷史**：供[契約容量最佳化](contract-capacity)使用
- **重新計算電費** 按鈕

系統內建台電「各類電價表」全部 20 種方案的預設價目，涵蓋表燈、低壓、高壓、特高壓。

### 第一次設定電費（建議流程）

1. **用電類別** 選貴公司所屬類別（例如高壓電力），**電價方案** 選帳單上的方案（例如時間電價二段式）
2. 核對 **夏月期間** 與各時段單價是否與帳單相符；若台電已調價或合約不同，直接修改後按 **儲存**
3. 在 **採用時間軸** 按 **新增採用**，**生效日（含當日）** 填**最早有電表資料的日期**，**採用方案** 選剛才的方案，按 **儲存採用時間軸**
4. 按 **重新計算電費**，勾選 **全量重算（自最早生效日至今日）**，按 **執行重算**，等候進度跑完（期間勿關閉視窗）
5. 到 EMS 首頁或[電費報表](electricity-cost)確認金額

> 💡 提示：直接按 **設為採用方案** 時，生效日會是**今天**，今天以前的日子不會計價。要讓歷史電費也有數字，請依上面步驟 3 在時間軸填較早的生效日。

### 採用時間軸

- 一列 = 「從某天起改用某方案」，每天的電費都套用**當天生效的方案**
- 時間軸上**沒有任何生效方案的日子不計算電費**（重算時這些日子的舊金額也會被清掉）
- 換約或換方案時，新增一筆採用紀錄即可，舊日期維持原方案
- 生效日建議**對齊電費月結期別的起始日**，避免同一期跨兩個累進方案造成級距計算偏低

### 時間電價（TOU）時段

- 每個方案依 **週一至週五** / **週六** / **週日及離峰日** × **夏月** / **非夏月** 各自設定時段與 **每度單價（元）**
- 每一組「日別 × 季節」的時段必須**剛好覆蓋 24 小時且不重疊**，否則無法儲存
- 訖時選 00:00 代表 24:00；起時晚於訖時代表跨午夜（例如 22:30～07:30）
- 可用 **加時段** / **刪除此時段** 調整，**區間名稱** 可自訂（留空顯示尖峰 / 半尖峰 / 離峰）
- [國定假日設定](holiday-shift)標註的日子，一律以 **週日及離峰日** 費率計價

### 累進、單一費率與超額加價

- **非時間電價（累進）**：按每月總度數分段計價，可 **加級距** / **刪除此級距**，級距會自動接續
- **非時間電價（單一費率）**：每度一個價錢，分夏月 / 非夏月
- **每月總度數超額加價**：簡易型時間電價專用，超過門檻（度）後每度加價

### 自訂方案

**用電類別** 選 **自訂**，可按 **新增方案** 從空白建立，或在台電方案按 **複製方案** 後修改。適用轉供、分租計價等情形，例如房東一度 5 元：建一個單一費率方案，夏月與非夏月都填 5。

- 自訂方案可刪除，但仍被採用時間軸引用時無法刪除
- 台電預設方案不可刪除；改壞了可按 **還原台電預設**（只還原這一個方案）

### 重新計算電費

電費會每小時自動計算，但**只會覆蓋最近 48 小時**。以下情況改完後，請按 **重新計算電費** 回溯受影響的區間：

- 修改了方案單價、時段、夏月期間
- 修改了採用時間軸
- 修改了[國定假日](holiday-shift)
- 新增或修正了歷史電表資料

操作：按 **重新計算電費** → 填 **起日（含）** / **訖日（含）**（上限 366 天），或勾 **全量重算** → **執行重算**。

> ⚠️ 注意：已算好的歷史電費**不會自動**跟著新費率改變，一定要手動重算。重算期間 EMS 卡片可能短暫顯示不一致的數字。

### 契約容量歷史

按 **新增契約紀錄**，填 **生效日（含當日）** 與各契約別 kW（依台電電費單），按 **儲存契約容量**。此資料只用於[契約容量最佳化](contract-capacity)回測，**不影響**本頁與報表的流動電費計算。

## 水費設定

<!-- IMG-TODO: ems/tariff-02 | 水費設定：方案版本下拉與分段累進級距表 | route=/WaterTariffSetting -->

系統預設台水流動水費四級距（1 度 = 1 m³）：

| 級距（度/月） | 單價（元/度） |
|---|---|
| 1–10 | 7.35 |
| 11–30 | 9.45 |
| 31–50 | 11.55 |
| 51 以上 | 12.075 |

### 方案版本與生效日

水費以「**方案版本**」管理，每個版本有自己的 **生效日**。計算某一期水費時，系統自動選用「生效日 ≤ 該期起始日」中最新的版本；期別比所有版本都早時，採用最早的版本。

### 調整費率的步驟（例如台水調價）

1. 按 **新增方案版本** —— 系統複製目前版本、生效日預設為今天
2. 修改 **方案名稱**、**生效日**（填調價生效日）與各級距 **單價（元/度）**；需要時按 **新增級距** / **刪除級距**
3. 按 **儲存**

這樣調價前的期別仍用舊版本計算，**歷史水費不會被改寫**。

> ⚠️ 注意：若直接修改**既有版本**的單價，所有使用該版本的期別（含過去）都會立即用新單價計算。要保留歷史金額，請用「新增方案版本」。

- 第一級須從 1 起算、級距連續、只有最後一級可以是「度以上」
- **還原台水預設** 會移除所有自訂版本，整份回到台水預設
- 每迴路以**自己**當期的總用水量套級距計算

## 氣費設定

天然氣沒有全國統一費率，系統預設是**空白範本**（一個級距、單價 0）。**第一次使用請依供氣合約帳單自行填入級距與單價**，否則氣費會全部是 0。

操作方式與水費完全相同：**新增方案版本**、**生效日**、**新增級距** / **刪除級距**、**儲存**，版本選用規則也相同。**還原預設範本** 會回到空白範本。

> ⚠️ 注意：級距與月結週期長度**無關**。若[氣費月結週期](billing-period)設成兩月一期，請直接填帳單上「一期」的級距數字，系統不會自動乘 2 或做任何換算。

## 改了費率，舊月份會變嗎？

| 費用 | 修改後的歷史月份 |
|------|------------------|
| 電費 | **不會自動變**，須按「重新計算電費」回溯 |
| 水費 / 氣費（新增版本） | 不變，只影響生效日之後開始的期別 |
| 水費 / 氣費（修改既有版本） | **立即變**，所有套用該版本的期別都重算 |
