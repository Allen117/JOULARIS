# 冰機 / 空壓機效率診斷

這兩頁用「產出 ÷ 耗電」的觀念評估冰水主機與空壓機的運轉效率：即時看每台機器現在效率好不好，也能看一天、一個月、一年的累計效率、負載分佈與設備排名，找出最耗電的那一台。

## 如何進入

- 導覽列 **設備效率 → 冰機效率診斷**
- 導覽列 **設備效率 → 空壓機效率診斷**
- 或在 EMS 首頁點 **冰機效率** / **空壓機效率** 卡片標題

頁面右上角的 **設備效率設定** 按鈕可前往設定頁。若尚未設定任何設備，頁面會顯示「尚未設定任何設備。」並提供 **前往設定（可自動掃描帶入）** 按鈕，請參考 [設備效率設定](equipment-efficiency-setting)。

## 效率指標怎麼看

### 冰機：kW/RT（越低越好）

**kW/RT** = 主機耗電 kW ÷ 產生的冷量 RT，意思是「每產生 1 冷凍噸冷量要花多少電」。例如 0.6 kW/RT 比 0.8 kW/RT 省電。

同時顯示：

- **COP** = 3.517 ÷ kW/RT（越高越好）
- **EER** = 12 ÷ kW/RT（越高越好）
- 冷量由**冰水流量 × 出回水溫差**逐分鐘計算；若主機只有直接 RT 讀值則用該值
- 有綁定時也會顯示 **負載率**、**冰水 ΔT**、**冷卻水 ΔT**、**蒸發器趨近**、**冷凝器趨近**

### 空壓機：比功率 kW/(m³/min)（越低越好）

**比功率** = 空壓機耗電 kW ÷ 每分鐘產生的空氣量 m³/min，意思是「每產生 1 m³/min 壓縮空氣要花多少電」。

同時顯示：

- **kW/100cfm** = 比功率 × 2.832（美規慣用單位）
- **比能耗** kWh/m³（累計期間才有）
- 有綁定時也會顯示 **排氣壓力**、**排氣溫度**、**加載** 狀態、**負載率**

### 評級

| 評級 | 意思 |
|------|------|
| **優** | 主指標 ≤「優」門檻 |
| **可** | 主指標 ≤「可」門檻 |
| **差** | 主指標 >「可」門檻 |
| **停機** | 設備沒有運轉，不計算效率 |
| **資料不足** | 沒有即時值或讀不到產出，無法相除（不會硬顯示 0） |

- **冰機門檻**預設「依標準」：依 ASHRAE 90.1 標準，根據冷卻方式、壓縮機形式、額定冷凍噸與定頻 / 變頻查出「標準滿載值」，**優 ≤ 標準值、可 ≤ 標準值 × 1.15**。卡片上會顯示門檻依據，例如「門檻 0.560 / 0.644」與機型說明
- **空壓機門檻**為手動設定，預設 7 / 9 kW/(m³/min)，請依銘牌或驗收報告調整
- 門檻可在 [設備效率設定](equipment-efficiency-setting) 修改

> 💡 提示：冰機評級只看主機本體，不含水泵與冷卻水塔，與 [能源申報](energy-declaration) 的「冰水系統 kWh/RTh」是不同指標。

### 即時區

每台設備一張小卡，每 30 秒自動更新，顯示：

- 運轉燈（**運轉中** / **停機** / **運轉狀態未知**）
- 主指標大字與評級顏色
- COP、EER 或 kW/100cfm 等次指標
- 耗電 kW、產出（冷量 RT 或空氣量）
- 輔助指標、門檻、**更新於** 時間

### 累計區

1. 點 **日** / **月** / **年** 切換期間
2. 在旁邊選日期、月份或年份
3. 下方內容隨即更新：

| 項目 | 內容 |
|------|------|
| 摘要數字 | **期間平均效率**、**總耗電**、總冷量 / 總空氣量、**運轉時數**、**平均負載率**；空壓機另有 **加載時間比**、**平均排氣壓力** |
| **效率趨勢** | 每台一條線，另有「全場加權」虛線 |
| **負載率分佈** | 運轉時數依平均負載率分成 ≤25 / 25–50 / 50–75 / >75% 四段，看各段的耗電占比與效率 |
| **設備排名（依期間平均效率）** | 每台的期間效率、**評級**、**運轉時數**、**平均負載 %**、**門檻**、**覆蓋率** |

期間一律用曆制：日（逐時）、月（每月 1 號到月底，逐日）、年（逐月），不受任何月結週期影響。

### 期間效率為什麼不是平均值

期間效率 = **期間總耗電 ÷ 期間總產出**（能量加權），而不是把每小時效率取平均。這樣低負載、短時間運轉的小時不會過度拉高或拉低結果，反映的是「這段期間實際每單位產出花了多少電」。

> ⚠️ 注意：若出現「資料覆蓋率 N%（… 缺 M 小時，低於 90%）」提示，代表有設備的流量計或溫度計在部分時段斷線，那些小時不計入效率，請檢查點位通訊。

## 空壓系統診斷（僅空壓機頁）

空壓機效率診斷頁上方有分頁：**效率儀表板**、**系統診斷**，工程師另可看到 **診斷設定**。

<!-- IMG-TODO: ems/equipment-efficiency-02 | 空壓機效率診斷：系統診斷分頁的觸發項目與建議下一步 | route=/CompressorEfficiency -->

**系統診斷** 每天凌晨 02:00 以最近 7 天的資料自動產生，依固定規則檢查空壓系統常見的節能機會：

| 分類 | 檢查項目 |
|------|---------|
| 前置：資料品質 | 點位覆蓋率、讀值長時間不變、運轉狀態與耗電矛盾等 |
| ① 壓力最佳化 | **壓力過高** |
| ② 洩漏與閒置損失 | **洩漏 / 閒置損失**（非生產時段仍有大量用氣） |
| ③ 運轉與排序 | **卸載比過高**、**停機延遲可縮短**、**頻繁加卸載循環**、**多台同時部分負載**、**調節機順序倒置**、**運轉但從不加載** |
| ④ 設備適配與生命週期 | **同工況比功率劣化**、**容量過大**、**容量不足**、**進氣節流機型** |

每項會標示狀態（**觸發** / **未觸發** / **資料不足** / **待補場域資料** / **待設定** / **不適用**），觸發者列出「篩檢節能 NT$ … ~ … / 年」與 **建議下一步**，部分項目附 **試驗檢查清單**。

> ⚠️ 注意：節能金額是**篩檢估計區間**，需經現場試驗或量測確認才算已驗證節能；各項節能也**不可直接相加**（例如降壓後洩漏量也會跟著變小）。標「依預設值」的結論表示用到尚未經現場確認的參數。

**診斷設定**（僅工程師）用來填入末端最低需求壓力、生產時段、系統級點位、劣化基準期與診斷參數；填得越完整，診斷越準確。工程師也可在系統診斷頁指定期間手動 **重算**。

## 常見狀況

| 狀況 | 原因與處理 |
|------|-----------|
| 小卡顯示「資料不足」 | 點位暫無即時值（網頁剛啟動或通訊中斷），或運轉中但產出為 0。等候片刻或檢查點位 |
| 機器明明在跑卻顯示「停機」 | 運轉判定依運轉狀態點；沒有該點時以耗電 ≤ 額定 5% 判定停機。請確認 [設備效率設定](equipment-efficiency-setting) 的額定電力是否正確 |
| 冰機門檻旁註記「機型未設定」或「未填額定 RT」 | 請到設定頁補上冷卻方式、壓縮機形式、定頻 / 變頻與額定冷量，評級才會準確 |
| 改了點位綁定，過去的累計效率沒變 | 新設定從下一個整點起生效；要重算過去資料請在設定頁使用 **回填歷史** |
| 系統診斷顯示「尚無排程診斷快照」 | 每日 02:00 才會產生；首次設定後請隔天再看 |
