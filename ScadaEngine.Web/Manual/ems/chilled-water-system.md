# 空調水系統迴路設定

本頁用來建立**空調水系統（冰水 / 冷卻水）的冷凍噸迴路階層**。冷凍噸報表、空調水系統迴路資訊、能源申報的冷凍噸（RT·h）與每冷凍噸耗電（kWh/RTh）、能源日報的冷凍噸時報表，都依這棵樹加總。

**進入方式**：**能管設定 → 空調水系統 → 空調水系統迴路設定**

> ⚠️ 注意：本頁與「自來水表」完全無關。這裡處理的是**冷凍能力（RT）**，不是用水量；自來水請到[自來水表/迴路設定](water-meter-setting)。

## 基本觀念

- 樹上的節點分成 **虛擬迴路**（不綁點位，用來分組加總）與 **實體點位**（綁一個 RT 點位）
- 綁定的點位是**瞬時冷凍噸（RT）**，系統每小時取平均值換算成冷凍噸小時（RT·h），報表上看到的就是 RT·h 的累計
- 瞬時值出現負數時（例如感測器漂移），系統一律當作 0 計算
- 虛擬迴路的值 = 底下所有實體點位的 RT·h 加總
- 與電表樹不同，本頁**沒有貢獻方向（正 / 反向）**，所有節點一律相加
- 可以有多個最上層節點（例如「一號冰水系統」「二號冰水系統」）

> 💡 提示：冷凍噸相關報表一律以**曆月**（每月 1 日到月底）統計，不受任何月結週期設定影響，詳見[月結週期](billing-period)。

- **左側「迴路階層」**：樹狀清單，滑鼠移到節點上出現 **新增子節點** / **編輯** / **刪除** 小按鈕
- **右上「新增迴路」**：建立最上層節點
- **右側詳情區**：顯示類型、名稱、點位名稱、單位、說明

## 新增迴路節點

1. 最上層按 **新增迴路**；子層在父節點上按 **新增子節點**
2. 輸入 **名稱**（例如「空調水系統」「冰機 1」）
3. 選 **節點類型**：**虛擬迴路** 或 **實體點位**
4. 選 **實體點位** 時：
   1. 在 **通訊設備** 下拉選設備
   2. 在 **對應點位** 下拉選點位 —— 只會列出單位為 RT 系列（RT / USRT / 噸 / 頓 / 冷凍噸）的點位
5. 選填 **說明**，按 **儲存**

> 💡 提示：若找不到冰機的冷凍噸點位，通常是點位單位沒有標成 RT 系列，請工程師確認點位單位，或用計算點位由流量與進出水溫算出 RT。

## 建議的樹狀結構

```
空調水系統（虛擬迴路）
├── 冰機 1（實體點位：冰機 1 冷凍噸）
├── 冰機 2（實體點位：冰機 2 冷凍噸）
└── 冰機 3（實體點位：冰機 3 冷凍噸）
```

能源申報等報表以「空調水系統」這類上層節點看全系統冷凍噸，以各冰機節點看單機。

## 拖曳搬移與刪除

- 節點可以用滑鼠拖曳換順序或搬到別的父節點底下，操作方式與[電表/迴路設定 § 拖曳搬移節點](electricity-meter-setting)相同
- 跨層搬動前會確認「搬動後上層迴路的冷凍噸加總與報表會立即改變」
- 拖到已綁定點位的節點底下時，會警告該節點會連自身一起加總
- 刪除含子節點的迴路時，會一併刪除所有子孫，並再次確認

## 注意事項

- **改結構會立即影響歷史報表**：冷凍噸報表、能源申報等依目前的樹重新加總，過去月份的數字也會跟著變
- 實體點位底下盡量不要再掛子節點，以免重複計算
- 若某些小時缺少資料，冷凍噸報表會顯示「資料不完整」的提示，請檢查冰機點位通訊

## 常見錯誤

| 狀況 | 原因與處理 |
|------|-----------|
| 儲存時出現「實體點位必須選擇對應 SID」 | 選了實體點位但沒有選對應點位 |
| 詳情顯示「⚠ 找不到對應的點位」 | 綁定的點位已被刪除或改名，請重新編輯並選擇點位 |
| 冷凍噸報表某月偏低並出現資料不完整警告 | 該月有冰機點位斷線，缺資料的小時不會計入 |
