# 能源基準

能源基準頁依 ISO 50001 / ISO 50006 的方法評估能源績效：先用過去一段期間的資料建立「能源基線」（能耗與天氣、產量等因素的關係），再用它判斷之後的能耗到底是真的變省了，還是只是天氣比較涼、產量比較少。

> 💡 提示：本功能是以 ISO 50001 方法評估能源績效的工具，並不代表通過 ISO 50001 驗證（驗證還需要政策、稽核、管理審查等制度面）。

## 如何進入

導覽列 **能源基準**

頁面有三個分頁：**基線建模**、**EnPI / 節能量報告**、**SEU 鑑別**。

## 基本觀念

```
相關變數 X（外氣溫度、產量…）→ 能源基線（回歸公式）→ 預測「照以前的習慣該用多少」→ 與實際比較 → 節能量
```

- 一般報表只能比「今年 vs 去年」的絕對值，容易被天氣、產量干擾
- 能源基線把這些外部因素扣掉，比的是「在同樣條件下」有沒有變省

### 建立模型

1. 在左側 **基線模型** 清單按 **新增模型**
2. 填寫 **模型名稱**、**說明**
3. 設定 **目標能耗 Y**（要預測的能耗），二選一：
   - **能源迴路**：選一個用電迴路，數字與 [用電報表](energy-report) 一致
   - **任意點位**：按 **選點位**，依「來源 → 設備 / 群組 → 點位」逐層挑選，或在第一層用搜尋框直接搜
4. 選任意點位時設定 **Y 取樣方式**：
   - **累計值（期初期末相減）**：kWh 這類累積電表
   - **瞬時值（期間均值）**：溫度、kW 這類即時量
   - 選點位後系統會依單位自動判斷，可再修改
5. 選 **取樣粒度**：**日粒度**（預設）或 **月粒度（曆月）**
6. 設定 **基線期起** / **基線期訖**（建議至少一年，涵蓋冷熱季節）
7. 在 **相關變數 X** 按 **加變數**，最多 5 個。每個變數選 **型別**：
   - **點位（均值）**：例如外氣溫度、濕度、產量
   - **迴路（kWh）**：例如某條迴路的用電
8. 按 **儲存模型**

### 跑回歸、看結果

1. 按 **建立基線（跑回歸）**
2. **回歸結果** 區會顯示：

   | 項目 | 怎麼看 |
   |------|--------|
   | **R²** / **調整後 R²** | 0～1，越接近 1 代表變數越能解釋能耗變化；低於 0.5 會提示解釋力弱 |
   | CV(RMSE) | 預測誤差相對於平均能耗的比例，越小越準 |
   | **樣本數** | 參與回歸的天數或月數 |
   | **截距 β0**、**係數表**（**係數 β**、**p-value**） | 每個變數對能耗的影響；p-value 越小代表該變數越顯著（一般以 < 0.05 為顯著） |
   | **基線公式** | 例如「能耗 = β0 + β1 × 外氣溫度 + …」 |
   | **實際 vs 預測散布圖** | 點越貼近對角線，模型越準 |

3. 若有取樣區間因 Y 或 X 缺值被剔除，會顯示「有 N 個取樣區間…被剔除」

> ⚠️ 注意：樣本數少於「變數數 × 5」時會提示模型可能不可靠。月粒度一年只有 12 筆，最多放 1～2 個變數；建議用日粒度。

### 凍結基線

模型滿意後按 **凍結基線**。凍結後係數固定，成為之後所有 EnPI 報告的比較基準，表單也會變成唯讀。

如需修改可按 **解除凍結**，但既有報告的比較基準會跟著改變。正式採用後建議不要再動，要調整請另建新模型。

## EnPI / 節能量報告

1. 在 **基線模型（限已凍結）** 選擇模型
2. 設定 **報告期起** / **報告期訖**（例如今年）
3. 按 **查詢**
4. 需要存檔時按 **匯出 Excel**

### 結果怎麼看

| 欄位 | 意思 |
|------|------|
| **實際** | 報告期實際能耗 |
| **基線預測** | 用凍結公式、代入報告期實際的 X 算出「照基線期習慣該用多少」 |
| **節能量** | 基線預測 − 實際；**正值代表比基線省** |
| **累計節能量** | 從報告期開始累加的節能量 |
| **EnPI** | 實際 ÷ 預測；**小於 1 代表優於基線** |

上方摘要顯示 **實際能耗合計**、**基線預測合計**、**累計節能量**、**整體 EnPI（實際÷預測）**。缺資料的期間標「資料不足（未列入統計）」。

## SEU 鑑別（重大能源使用）

找出全廠用電大戶，作為節能改善的優先對象。

1. 設定 **期間起** / **期間訖**
2. 設定 **累計占比門檻**（預設 80%）
3. 按 **分析**

系統以主要電表的直接子迴路為單位，依用電量由大到小排名，並畫出帕累托圖（長條 + 累計占比折線）。累計占比達門檻之前的項目（含跨過門檻的那一項）標為 **SEU**。表格欄位為 **排名**、**能源使用**、**用電量 (kWh)**、**占比**、**累計占比**。

> 💡 提示：這就是「80/20 法則」——通常少數幾條迴路就占了大部分用電，先從這些著手改善效益最大。

## 注意事項

- 本頁的「月」固定為**曆月**，與用電報表的電費期別不同，屬刻意設計（讓溫度等變數以自然時間對齊）
- 只取已經過完的天或月，未完成的半天 / 半月不進回歸
- 同一個點位重複選兩次之類的變數組合，p-value 可能顯示「—」，請勿盲目增加變數

## 常見狀況

| 狀況 | 原因與處理 |
|------|-----------|
| EnPI 分頁的模型下拉顯示「（尚無已凍結的基線）」 | 先在基線建模分頁跑回歸並 **凍結基線** |
| SEU 顯示「找不到可分析的迴路」 | 先到 [電表/迴路設定](electricity-meter-setting) 建立迴路，並設定主要電表 |
| R² 很低 | 選的變數與能耗關係不大，試著換成外氣溫度、產量等真正影響用電的因素 |
| 凍結後無法修改模型 | 屬正常；需要修改請 **解除凍結**，或另建新模型 |
