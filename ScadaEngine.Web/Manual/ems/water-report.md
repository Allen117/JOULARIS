# 用水與水費報表

這一章包含兩個頁面：**用水報表** 查詢自來水用量（m³），**水費報表** 依台水流動水費級距逐期試算水費。

> ⚠️ 注意：這裡的「水」是自來水表的用水量，與空調水系統（冰水主機冷量）無關。

## 如何進入

- 導覽列 **報表查詢 → 用水報表**
- 導覽列 **報表查詢 → 水費報表**

## 用水報表

### 畫面說明

<!-- IMG-TODO: ems/water-report-01 | 用水報表：用水量分布長條圖與數據明細 | route=/WaterUsageReport -->

- **查詢條件**：**迴路**、**單位**（**時** / **日** / **月** / **年** / **班別**）、起訖時間、**查詢**、**匯出 Excel**
- **用水量分布**：長條圖，下方顯示 **總計**
- **數據明細**：**時段** / **用水量 (m³)**，最後一列 **合計**

### 查詢步驟

1. 選 **迴路**（上層為合計，最上層通常就是全廠用水）
2. 選 **單位** 並填起訖時間
3. 按 **查詢**
4. 需要存檔時按 **匯出 Excel**（選上層迴路時，每個直接子迴路會多一欄）

操作方式與 [用電報表](energy-report) 相同，包含：

- **顯示明細** / **顯示合計**：上層迴路有兩個以上子迴路時，可切換堆疊長條
- **班別**：依 [國定假日與班別](holiday-shift) 的班別定義，把每天拆成各班一列，另有「非班別」列補足其餘時段

### 「月」是水費期別

用水報表的「月」依 [月結週期](billing-period) 中的**水費期別**切分（與電費期別各自獨立，因為台水與台電的抄表日不同）。選月單位時會顯示「期別實際區間」提示；未設定時就是自然月。

### 讀數說明

- 每小時用水量 = 該小時結束時的水表累積讀數 − 開始時的讀數，每小時整點後幾分鐘彙整
- 水表若以公升計，系統會自動換算，報表一律以 **m³** 顯示
- 上層迴路 = 子迴路加總；設為「扣除」的子迴路會被減掉
- 表格某格出現提示「此區間水表資料不完整（可能斷線）」時，代表該時段有水表斷線，數字可能偏低

## 水費報表

水費報表以「期」為單位：每一期的總用水量套用台水流動水費的分段累進級距，算出該期水費。

### 畫面說明

<!-- IMG-TODO: ems/water-report-02 | 水費報表：各期水費長條圖與可展開級距明細的期別明細表 | route=/WaterCostReport -->

- **查詢條件**：**自來水表迴路**、**起始期別**、**結束期別**、**查詢**、**匯出 Excel**；下方顯示「期別區間」
- **各期水費**：每期一根柱；上方顯示 **總水費** 與 **總用水量**
- **期別明細**：**期別** / **用水量 (m³)** / **套用方案** / **水費（元）** / **明細**

### 查詢步驟

1. 選 **自來水表迴路**
2. 選 **起始期別** 與 **結束期別**
3. 按 **查詢**
4. 在某期按 **明細** 欄的展開鈕，可看該期每一級距的 **級距（度）**、**單價（元/度）**、**度數 (m³)**、**金額（元）**
5. 需要存檔時按 **匯出 Excel**

### 水費怎麼算

- 1 度 = 1 m³
- 依 [費率設定](tariff) 的水費方案分段累進。台水預設級距為：

  | 每期用水度數 | 單價（元/度） |
  |-------------|--------------|
  | 1–10 | 7.35 |
  | 11–30 | 9.45 |
  | 31–50 | 11.55 |
  | 51 以上 | 12.075 |

  例：一期用 40 度 = 10 × 7.35 + 20 × 9.45 + 10 × 11.55 = 378 元
- 每一期採用「該期**起始日**當天有效」的方案版本，所以調整費率後，歷史各期水費不會被改寫
- 每個迴路**各自**以自己的用量套級距（不是按比例分攤全廠水費）

> ⚠️ 注意：水費報表只算**流動水費**，不含按水表口徑計收的基本費，因此會比實際帳單少。

## 常見狀況

| 狀況 | 原因與處理 |
|------|-----------|
| 迴路下拉沒有選項 | 先到 [自來水表/迴路設定](water-meter-setting) 建立迴路 |
| 水費期別欄出現 **資料不完整** 標記 | 該期用水量彙總時有水表斷線，金額僅供參考 |
| 出現「⚠ 部分時段水表資料不完整（可能斷線）」 | 請到 [趨勢圖](../scada/history) 檢查水表點位通訊 |
| 水費與台水帳單差很多 | 檢查期別起訖是否與帳單抄表日相同（[月結週期](billing-period)），以及費率是否與帳單一致（[費率設定](tariff)）；另外本報表不含基本費 |
| 改了水費月結週期，電費報表沒變 | 兩者各自獨立，屬正常 |
