# 常見問題

本章整理 EMS 使用上最常遇到的問題。各功能的詳細說明請見對應章節。

## 報表沒有數字 / 數字不對

### 報表某個月是空白或 0

可能原因與檢查方式：

1. **電表在該月斷線**：用電報表該格會顯示琥珀色 ⚠，滑鼠移上去提示「此區間電表資料不完整（可能斷線）」。斷線期間抓不到讀數，系統以 0 顯示而不是猜測
2. **電表是月中才上線**：該格會顯示藍色 ◐，代表「邊界缺讀數，僅統計區間內有讀數的區段」—— 數字只算有讀數的那段
3. **讀數倒退且沒設溢位上限**：電表 / 水表 / 氣表歸零或換表時，若沒有填 MaxKwh 或 MaxVolume，該時段以 0 計。請到對應的迴路設定頁補填
4. **月結期別有空窗**：期別之間有空窗時，空窗那幾天的用量不會算進任何月份，請檢查[月結週期](billing-period)的「連續性」欄位
5. **查的是未來或尚未開始的期別**：當期未過完時，報表統計到「現在」為止

### 用水 / 用氣報表最近一小時沒有數字

用水、用氣、產氣量、冷凍噸每小時彙整一次，最近一小時要等下一個整點過後幾分鐘才會出現。用電報表則是即時計算，當下就看得到。

### 為什麼某個電表沒有出現在報表裡？

- **報表只看迴路樹**：電表點位必須先在[電表/迴路設定](electricity-meter-setting)建成節點，報表的迴路下拉才會出現
- **點位清單找不到電表**：電表頁只列單位為 **kWh** 的累積點位；水表頁只列 m³ / 公升；氣表頁還要求點位名稱含天然氣字樣。單位或名稱不符時，請工程師修正點位
- **EMS 首頁卡片沒有它**：主要電表的圓餅圖與比較表只列主要電表的**直接子迴路**；用水 / 用氣卡片以樹的**最上層節點**當全廠
- **沒有權限**：看不到某些報表或設定頁時，請管理員在帳號管理中開放該頁

### 同一個月，用電報表和能源申報的度數不一樣

正常。用電報表的「月」依**電費月結週期**切分（例如 6/16～7/17），能源申報、冷凍噸報表、能源基準、設備效率一律用**曆月**（1 日～月底）。詳見[月結週期](billing-period)。

### 改了迴路樹，過去月份的報表數字也跟著變了

正常。所有報表都是依**目前**的迴路樹即時加總，搬移、刪除、改貢獻方向後，過去月份也會用新結構重新計算。需要保留某個時點的報表，請事先匯出 Excel。

### 報表出現負值

迴路有設定「反向（從父扣減）」時，扣減的量大於加入的量就會是負值，例如「其他用電 = 總表 − 各分表」而分表加總大於總表。請檢查是否有分表重複放置，或貢獻方向設錯。

## 費用問題

### 系統算的電費和台電帳單對不起來

常見原因：

| 原因 | 說明 |
|------|------|
| 不含基本電費 | 系統只計算**流動電費**，契約容量的基本電費不計入 |
| 電費報表不含超額加價 | 簡易型時間電價的每月超額加價，EMS 電費狀態卡有計入，電費報表沒有 |
| 期別不同 | [電費月結週期](billing-period)未照帳單抄表日設定 |
| 方案或單價不同 | [費率設定](tariff)中的採用方案、單價、夏月期間與帳單不符 |
| 國定假日未標註 | 時間電價下，未標註的假日會被當平日計價，請檢查[國定假日設定](holiday-shift) |
| 改了設定沒重算 | 修改費率、採用時間軸或假日後，須按「重新計算電費」才會更新歷史金額 |
| 電表資料有缺 | 斷線期間度數為 0，電費也是 0，會**低估**電費 |
| 累進方案為近似值 | 夏月 / 非夏月跨月時以度數占比估算，與台電按日數分計可能有小差異；子迴路金額為依度數占比分攤的估算值 |
| 電表與台電表計量差異 | 廠內電表與台電計費表本身會有些微誤差 |

### 電費報表顯示「該區間尚無電費資料」

尚未設定採用方案，或採用時間軸的生效日晚於查詢區間。請到[費率設定](tariff)的「採用時間軸」新增較早的生效日，再執行「重新計算電費」。

### EMS 電費卡顯示「尚未選擇電費方案」

尚未在[費率設定](tariff)選定採用方案。

### 改了電費單價，舊月份的電費沒變？

電費是逐小時算好保存的，修改費率、採用時間軸或國定假日後，**已算過的歷史不會自動更新**。請到[費率設定](tariff)按 **重新計算電費**，選擇要回溯的區間（或勾全量重算）。

### 改了水費 / 氣費單價，舊月份怎麼也變了？

水費、氣費是查詢時即時計算的。若直接修改**既有方案版本**的單價，所有套用該版本的期別都會用新單價。要讓調價只影響之後的期別，請用 **新增方案版本** 並填入調價的生效日，詳見[費率設定](tariff)。

### 氣費全部是 0

氣費預設是空白範本（單價 0），請依供氣合約帳單在[費率設定 § 氣費設定](tariff)填入級距與單價。

### 改了月結週期，要重新計算嗎？

不需要。月結週期改完即時生效，報表與電費都會依新期別重新切分。

## 設定問題

### 拖曳不了節點

- 自來水表、氣表、產氣量表的**最上層全廠節點不能拖動**，也不能把其他節點拖成第二個最上層
- 不能把節點拖到自己的子節點底下
- 平板等觸控裝置不支援拖曳，請改用電腦滑鼠操作

詳見[電表/迴路設定 § 拖曳搬移節點](electricity-meter-setting)。

### EMS 首頁某些卡片不見了

可能在[卡片顯示設定](ems-card-setting)中被隱藏，或您的帳號沒有相關頁面權限。

### 日報收不到信

1. 檢查[日報設定](daily-report-setting)是否勾選自動寄送、收件人是否 **啟用**
2. 按 **測試寄送** 確認
3. 若測試也失敗，請確認警報通知的 Email 設定能正常寄信（日報沿用同一組郵件伺服器設定）
