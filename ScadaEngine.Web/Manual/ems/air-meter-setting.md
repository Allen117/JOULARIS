# 產氣量表/迴路設定

本頁用來建立**空壓機累積產氣量（壓縮空氣）的迴路階層**。這棵樹唯一的用途，是作為[空壓機能源申報](air-compressor-declaration)計算比能耗（kWh/Nm³）時的**產氣量分母**。

**進入方式**：**能管設定 → 產氣量表 → 產氣量表/迴路設定**

> ⚠️ 注意：壓縮空氣不可以放進[氣表](gas-meter-setting)，那裡是天然氣、會被計算氣費；天然氣也不可以放進本頁。

## 基本觀念

本頁的版面與操作和[氣表/迴路設定](gas-meter-setting)相同：

| 項目 | 產氣量表 |
|------|----------|
| 節點類型 | **虛擬迴路** / **實體產氣量表** |
| 可綁的點位 | 流量計的**累積量**點位（Nm³、m³、SCM、公升、NL 等），名稱需含空壓關鍵字 |
| 單位換算 | 一律換算成 Nm³（m³ 視同 Nm³，系統不做溫壓修正） |
| 溢位處理 | **溢位上限 MaxVolume**（以點位原始單位填寫） |
| 貢獻方向 | 有，**正向（加入父）** / **反向（從父扣減）** |
| 最上層節點 | **只能有一個**（代表全廠） |
| 期別 / 費率 / 報表 | **都沒有**，數字只在空壓機能源申報頁以曆月呈現 |

## 新增產氣量表節點

1. 按 **新增產氣量表/迴路** 建立根節點，例如「空壓機房總產氣」
2. 在根節點上按 **新增子節點**，例如「1 號空壓機」
3. 選 **節點類型**：
   - **虛擬迴路**：不綁點位，加總子節點（例如總產氣 = 1 號 + 2 號 + 3 號）
   - **實體產氣量表**：按 **選擇點位** → 選 **通訊設備** → 選 **點位** → **確定**
4. 選擇 **貢獻方向**，視需要填 **溢位上限 MaxVolume**（流量計累積值會歸零時使用）
5. 按 **儲存**

## 為什麼找不到我的產氣量點位？

點位要同時符合三個條件才會列出：

1. **單位是累積量**：Nm³、m³、SCM、公升、NL 等（不收「度」）
2. **名稱含空壓關鍵字**：「空壓」「壓縮空氣」「產氣」「氣量」「air」「compressor」「FAD」
3. **名稱不含天然氣字樣**：含「天然氣」「瓦斯」「燃氣」「LNG」等的點位一律排除

| 原因 | 處理 |
|------|------|
| 點位名稱沒有空壓字樣 | 請工程師把名稱改成含「空壓」「壓縮空氣」「產氣量」等字樣 |
| 綁的是瞬時流量（Nm³/min、Nm³/h） | 改綁流量計的**累積量**點位（Nm³） |

## 拖曳搬移與刪除

- 操作方式與[電表/迴路設定 § 拖曳搬移節點](electricity-meter-setting)相同
- 根節點不能拖動、不能拖成第二個根；跨層搬動前確認「搬動後上層迴路的加總與申報數字會立即改變」
- 刪除含子節點的迴路會一併刪除所有子孫

## 注意事項

- **改結構會立即影響空壓機能源申報**的歷史月份數字
- 產氣量每小時彙整一次，當月（進行中）的數字最後一小時可能尚未計入
- 已彙整的歷史資料不會因事後修改溢位上限而自動重算
