# 空壓機能源申報

空壓機能源申報與 [能源申報](energy-declaration) 的操作方式相同，差別在第二個來源是「產氣量表」：把一條用電迴路與一條產氣量表迴路配成一組，產出整年 12 個月的**用電量、產氣量與比能耗（kWh/Nm³）**，並可匯出 Excel。

## 如何進入

導覽列 **報表查詢 → 空壓機能源申報**

> 💡 提示：本頁與冰水系統的能源申報權限分開，管理員可以分別開放。

## 開始前的準備

先到 **能管設定 → 產氣量表 → 產氣量表/迴路設定** 建立產氣量表迴路，詳見 [產氣量表/迴路設定](air-meter-setting)。多台空壓機可以用一個上層（虛擬）迴路把各台產氣量加總。

> ⚠️ 注意：這裡的「產氣量」是空壓機產生的壓縮空氣（Nm³），與天然氣表完全無關。

## 什麼是比能耗

**比能耗（kWh/Nm³）** = 用電量 ÷ 產氣量，代表「每產生 1 標準立方公尺壓縮空氣要花多少度電」，**數值越低越省電**。

- 例：某月用電 30,000 kWh、產氣 250,000 Nm³ → 比能耗 = 0.120 kWh/Nm³
- **整體比能耗** = 全年總用電 ÷ 全年總產氣量（加權值，不是各月比能耗的平均）
- 本頁不做溫度、壓力修正

## 建立申報報表

<!-- IMG-TODO: ems/air-compressor-declaration-01 | 空壓機能源申報：新增申報報表視窗（用電迴路 + 產氣量表迴路） | route=/AirCompressorDeclaration -->

1. 在 **申報報表設定** 卡片按 **新增報表**
2. 填寫：
   - **報表名稱**：例如「空壓一廠」
   - **用電度數來源（用電迴路）**：空壓機的用電迴路
   - **產氣量來源（產氣量表迴路）**：對應的產氣量表迴路
   - **描述**：選填
3. 按 **儲存**

兩個來源都必填。若下拉顯示「-- 尚無迴路，請先建立 --」，請先建立對應的迴路。

## 查詢申報資料

1. 在 **查詢條件** 選 **申報報表**
2. 輸入 **申報年度**（預設今年）
3. 按 **查詢**，固定產出 1～12 月（每月 1 號到月底）
4. 需要存檔時按 **匯出 Excel**

### 結果怎麼看

- **用電量與產氣量分布**：用電量 (kWh) 長條 + 產氣量 (Nm³) 折線；滑鼠移到某月會顯示「比能耗：… kWh/Nm³」
- **數據明細**：**月份** / **用電量 (kWh)** / **產氣量 (Nm³)** / **kWh/Nm³**，最後一列 **合計**
- 下方顯示 **總用電量**、**總產氣量**、**整體比能耗**
- 產氣量為 0 的月份比能耗顯示 `--`

同一條用電迴路、同一年度的用電量，與 [能源申報](energy-declaration) 頁的數字完全一致。

## 匯出的 Excel

包含報表名稱、用電迴路、產氣量來源、申報年度、查詢時間、操作者，以及 12 個月的四欄資料與合計列。

## 表格中的標記與警告

| 標記 / 訊息 | 意思 |
|------|------|
| ⚠ | 此月電表或產氣量表資料不完整（可能斷線） |
| ◐（藍色） | 此月電表邊界缺讀數，僅統計月內有讀數的區段 |
| 「⚠ 部分電表資料不完整或累積值倒退但未設 MaxKwh」 | 請檢查電表通訊，或到 [電表/迴路設定](electricity-meter-setting) 補上溢位上限 |
| 「⚠ 部分產氣量表資料不完整（可能斷線）」 | 產氣量表有斷線，產氣量可能偏低、比能耗偏高 |

## 常見狀況

| 狀況 | 原因與處理 |
|------|-----------|
| 清單顯示紅字「來源已不存在」 | 綁定的迴路已被刪除，請按 **編輯** 重新選擇 |
| 當月產氣量偏低 | 當月尚未結束，且產氣量每小時整點後幾分鐘才彙整 |
| 想看單台空壓機的即時比功率 | 請改用 [冰機 / 空壓機效率診斷](equipment-efficiency) 的空壓機頁 |
