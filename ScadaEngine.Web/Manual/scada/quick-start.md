# 快速開始

本章帶您認識系統的基本操作：登入與登出、畫面上方導覽列的各個按鈕、切換語系、在 SCADA 與 EMS 之間切換、搜尋頁面、處理警報聲音，以及如何隨時打開本手冊。

> 💡 提示：每位使用者看得到的選單不一定相同。一般操作人員只會看到管理員開放給自己的頁面；若找不到某個功能，請洽系統管理員確認權限。

## 登入系統

1. 開啟瀏覽器（建議使用 Chrome 或 Edge），輸入管理員提供的系統網址。
2. 在登入畫面的 **系統登入** 區塊輸入 **使用者名稱** 與 **密碼**。
3. 若這台電腦是您個人專用，可勾選 **記住我**，之後一段時間內開啟系統不必重新登入。
4. 按 **立即登入**。

登入成功後，系統會直接進入 **即時監控** 畫面。

> ⚠️ 注意：公用電腦或中控室共用電腦請**不要**勾選 **記住我**，以免其他人以您的身分操作設備。

> 💡 提示：沒勾選 **記住我** 時，一段時間沒有操作會自動登出，重新登入即可；持續使用中則會自動延長，不會被中途踢出。

若出現「使用者名稱或密碼錯誤」，請確認大小寫與輸入法是否正確。忘記密碼請洽系統管理員（見 [常見問題](faq)）。

## 登出系統

1. 點導覽列最右側的使用者名稱（人像圖示）。
2. 選 **登出**。
3. 出現 **確認登出** 視窗，按 **確認登出** 即完成；按 **取消** 則留在原頁面。

## 切換語系

1. 點導覽列右側的地球圖示（旁邊顯示目前語系 **台灣** 或 **EN**）。
2. 選 **繁體中文** 或 **English**。
3. 頁面會自動重新整理，選單與頁面文字改為所選語言。

> 💡 提示：語系設定記在您目前使用的瀏覽器上，換一台電腦需重新選擇。點位名稱、設備名稱等現場自行命名的文字不會跟著翻譯。

> ⚠️ 注意：少數頁面（例如登入頁、個人資料、無權限提示頁）目前只有中文，切到英文時仍顯示中文，屬正常現象。

## 在 SCADA 與 EMS 之間切換

本系統分為兩大區塊：

- **SCADA 監控系統**：即時監控、控制、趨勢與警報（本手冊內容）。
- **EMS 能源管理**：用電、用水、用氣報表、電費與效率分析，導覽列會變成綠色主題。

在 SCADA 畫面按右上角 **回 EMS** 即可進入 EMS；在 EMS 畫面按 **回 SCADA** 即可回來。按鈕只會出現在您有權限的那一邊。EMS 的操作說明請見「EMS 使用手冊」。

## 全站搜尋

不記得某個頁面放在哪個選單時，可以直接搜尋頁面名稱。

1. 點導覽列的放大鏡圖示，或在鍵盤按 `Ctrl` + `K`（Mac 為 `Cmd` + `K`）。
2. 在 **搜尋頁面名稱…** 欄位輸入關鍵字，例如「趨勢」「警報」。
3. 用 `↑` `↓` 選擇結果，按 `Enter` 前往；按 `Esc` 關閉視窗。也可以直接用滑鼠點選結果。

- 中文或英文都能搜，例如在中文介面輸入 `report` 也找得到各種報表。
- 輸入框空白時，會列出您 **最近使用** 過的頁面。
- 搜尋結果只會列出您有權限進入的頁面；EMS 的頁面會附上綠色葉子標記。

## 警報鈴鐺與警報音

登入後，不論停在哪一頁，只要有新的未確認警報，電腦就會發出警報音，導覽列的鈴鐺也會閃爍並顯示筆數。

### 什麼時候會響

| 警報嚴重程度 | 聲音 |
|--------------|------|
| 緊急 | 急促的高低交替嗶聲，持續響到警報被確認、消音或恢復為止 |
| 高 | 雙嗶聲，持續響到警報被確認、消音或恢復為止 |
| 中 | 每出現一筆新警報響一次「叮咚」 |
| 低 | 不發聲 |

在 **即時監控** 畫面下方的 **未恢復警報** 面板雙擊該筆警報完成「確認」後，該筆就不再響（見 [即時監控](scada-page)）。

### 鈴鐺選單

點鈴鐺會展開選單，最上方顯示目前狀態（例如「2 筆未確認警報響鈴中」），下方可操作：

| 選項 | 效果 |
|------|------|
| **消音（新警報仍會響）** | 讓目前正在響的警報停止發聲；之後再出現新的警報仍會響 |
| **暫時靜音** → **5 分鐘** / **15 分鐘** / **30 分鐘** | 這段時間內完全不響，時間到自動恢復 |
| **取消靜音** | 立即解除消音或暫時靜音（有靜音時才會出現） |
| **測試警報音** | 播放一輪緊急警報音，用來確認喇叭與音量 |
| **查看未恢復警報** | 前往可查看警報的頁面 |

> 💡 提示：消音與靜音只影響**您這台電腦**，不會讓其他值班電腦也跟著安靜。

> ⚠️ 注意：瀏覽器規定網頁必須先被點過一下才能發聲。如果鈴鐺左邊出現紅色的 **點此啟用警報音**，請點它一下，否則警報來時不會有聲音。每次重新開啟瀏覽器後，建議先按一次 **測試警報音** 確認。

## 個人資料

1. 點導覽列右側的帳號名稱。
2. 選 **個人資料**。

頁面會顯示您的 **帳號**、**姓名**、**角色**、**部門**、**帳號狀態**、**最後登入時間** 等資訊。一般使用者（User）還會看到 **頁面存取權限**，列出管理員開放給您的主功能頁面與 **即時監控子頁面**。

### 變更密碼

目前畫面上沒有提供使用者自行變更密碼的功能。若需要更換密碼或忘記密碼，請聯絡系統管理員協助處理。

## 開啟使用手冊

導覽列上的書本圖示可以隨時打開 **使用手冊**：

- 在某個功能頁按書本圖示，如果手冊裡有這一頁的說明，會**直接跳到對應章節**。例如在趨勢圖頁按下，就會開啟「趨勢圖」這一章。
- 若該頁沒有專屬章節，則會開啟該頁所屬的手冊目錄。
- 手冊左側是 **章節目錄**，右側是 **本頁目錄**，可快速跳到段落；也可以按 **列印**。

> 💡 提示：手冊只會列出您有權限使用的功能章節，所以每個人看到的目錄可能不一樣。

## 畫面上方出現紅色警示條

若頁面頂端出現紅色橫條「Engine 授權驗證失效 — 資料採集已暫停」，表示系統授權驗證出了問題，現場資料暫時停止更新。處理方式請見 [常見問題](faq)。
