# 氣象資料

**氣象資料** 頁用來設定系統自動向中央氣象署抓取附近測站的**外氣溫度**與**外氣相對濕度**。抓到的資料會變成系統中一般的點位，可以在即時數據、趨勢圖、警報、能源基準等功能中使用。

系統除了溫度、濕度外，也會自動推算外氣濕球溫度、焓值與露點溫度，供空調相關分析使用。

## 進入頁面

點導覽列 **系統設定 → 氣象資料**。頁面標題為 **氣象資料來源設定**。

## 第一次設定

### 1. 申請授權碼

1. 前往中央氣象署開放資料平台（opendata.cwa.gov.tw）免費註冊會員。
2. 登入後取得授權碼（以 `CWA-` 開頭的一串文字）。
3. 回到本頁，貼到 **中央氣象署開放資料授權碼** 欄位。

> ⚠️ 注意：每個廠區請使用自己申請的授權碼，不要和其他廠區共用。授權碼的流量是分開計算的，共用的授權碼一旦重新產生，所有使用它的現場會同時失效。

### 2. 選擇測站

1. 填好授權碼後，按 **載入測站清單**。成功時會提示「已載入 N 個測站」。
2. 先選 **縣市**，再選 **測站**。清單中會標示測站類型：**自動站**（數量多、遍布各鄉鎮）或 **署屬站**（主要城市、品質較高）。建議選擇離廠區最近的測站。
3. 按 **測試連線**，畫面會立即顯示該測站目前讀到的溫度、相對濕度與觀測時間，確認資料正確。

清單只會列出目前溫度與濕度都有正常回報的測站。

### 3. 設定抓取與啟用

1. **抓取間隔（分鐘）**：可填 5～1440，預設 10。氣象署的觀測資料大約每 10 分鐘才更新一次，設得更短並沒有幫助。
2. 勾選 **啟用自動抓取**。
3. 按 **儲存**。畫面提示「設定已儲存，背景服務最慢 30 秒內套用」。

> 💡 提示：啟用前必須先填入授權碼並選好測站，否則無法儲存。

## 查看執行狀態

**執行狀態** 區塊每 30 秒自動更新，顯示 **最近抓取時間**、**結果**（**成功** / **失敗**）與 **訊息**。

| 訊息 | 意思與處理 |
|------|------------|
| 溫度 … °C、相對濕度 … %（觀測時間 …） | 正常 |
| 部分欄位缺測 | 測站暫時沒有回報某個項目，缺的點位會標為品質不良，通常會自行恢復 |
| 觀測資料過舊 | 測站超過 60 分鐘沒有新資料，點位標為品質不良；若持續發生，請改選其他測站 |
| 查無所選測站 | 測站可能已裁撤，請重新選擇測站 |
| 氣象署 API 授權失敗 | 授權碼無效或已過期，請重新確認授權碼 |
| 無法連線氣象署 API | 主機無法連上網際網路，請洽 IT 人員確認防火牆可連線 opendata.cwa.gov.tw |
| Engine 尚未載入 Weather 點位設定 | 系統尚未完成氣象點位的安裝設定，請洽工程師 |
| 已停用 | 自動抓取未啟用 |

## 在哪裡看到氣象資料

氣象資料會出現在名為「Weather」的資料來源設備底下（S1＝外氣溫度、S2＝外氣相對濕度，另有濕球溫度、焓值、露點溫度），可以：

- 在 [即時數據](realtime) 查看目前數值。
- 在 [趨勢圖](history) 查看歷史曲線，或與室內溫度、用電量一起比較。
- 在 [警報設定與通知](alarm-setting) 設定外氣溫度警報。

> 💡 提示：抓取失敗或資料過舊時，點位會標為品質不良並保留最後一筆成功的數值，避免把舊資料當成最新資料使用。

## 更換測站

直接在 **測站選擇** 改選其他測站並按 **儲存** 即可。點位編號不變，原本使用這些點位的趨勢圖、警報等設定都不受影響。
