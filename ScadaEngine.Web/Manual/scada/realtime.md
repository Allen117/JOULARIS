# 即時數據

**即時數據** 以表格方式列出系統中所有點位的最新數值、單位、品質與更新時間。不需要圖形畫面時，這是快速查看「某個點位現在是多少」最直接的地方，也很適合用來檢查哪些點位通訊異常。

## 進入頁面

點導覽列的 **即時數據**。頁面標題為 **SCADA 即時監控儀表板**。

| 區域 | 說明 |

| 右側 **即時資料監控** | 點位表格，標題旁顯示目前列出的筆數 |
| 表格下方 | 顯示 **自動更新週期: 3 秒** 與 **最後更新** 時間 |

## 篩選設備

1. 在左側 **設備清單** 點選一台設備，右側表格就只列出該設備的點位。
2. 若設備旁有箭頭，表示底下還有多台子設備：點一下展開，再點子設備名稱即可只看那一台。
3. 點 **計算點位** 可只看系統依公式算出來的點位（例如總和、效率）。
4. 資料庫來源類的設備同樣可以展開，選擇個別來源。

被選中的項目左側會出現藍色標示。

## 表格欄位

| 欄位 | 說明 |
|------|------|
| **名稱** | 點位名稱 |
| **SID** | 點位的系統編號，回報問題時可提供給工程師 |
| **數值** | 目前數值；尚無資料時顯示 `--` |
| **單位** | 數值單位 |
| **品質** | 資料品質標籤，見下表 |
| **時間戳記** | 這筆數值的更新時間（月-日 時:分:秒） |

### 排序

點任何欄位的標題（旁邊有 ⇅ 符號）即可依該欄排序，再點一次可反向排序。例如點 **品質** 可以把異常點位集中在一起。

## 判讀顏色與品質

### 品質標籤

| 標籤 | 顏色 | 意思 |
|------|------|------|
| GOOD | 綠 | 正常 |
| UNCERTAIN | 黃 | 資料可信度不確定 |
| STALE | 黃 | 超過 5 分鐘沒有收到新資料，畫面保留最後一筆數值 |
| BAD | 紅 | 通訊失敗或讀值異常 |
| NO_DATA | 灰 | 系統啟動以來從未收到這個點位的資料 |

### 整列底色

| 底色 | 意思 |
|------|------|
| 白色 | 正常，近 1 分鐘內有更新 |
| 黃色 | 資料過舊（超過 1 分鐘未更新）或品質為 STALE |
| 紅色 | 品質不良（例如 BAD） |
| 灰色 | 尚無資料，數值顯示 `--` |

數值有變動時，該格會短暫閃一下黃色，方便您注意到變化。

## 更新方式

- 頁面每 **3 秒** 自動更新一次，不需要手動重新整理。
- 想立即更新時，按標題列的 **重新整理**。

## 常見狀況

| 狀況 | 處理方式 |
|------|----------|
| 標題列顯示 **連線異常** | 網頁伺服器與資料來源的連線中斷，數值不會更新；請通知工程師 |
| 表格顯示「尚無即時資料，請確認 MQTT 連線狀態」 | 系統尚未收到任何即時資料，請通知工程師檢查資料採集服務 |
| 某台設備所有點位都是紅底或黃底 | 該設備可能斷線、斷電或通訊線路異常，請先確認現場設備，再通知工程師 |
| 出現「網路請求失敗，請檢查連線」 | 您的電腦與系統伺服器之間的網路中斷，請檢查網路後按 **重新整理** |

> 💡 提示：要看某點位的歷史變化，請到 **歷史資料 → 趨勢圖**，見 [趨勢圖](history)。
