# 線上使用手冊 — 內容寫作規範

本資料夾是 Web「使用手冊」（`/Manual`）的內容來源，**不是**開發文件。
開發者文件在 `docs/功能說明書_*.md`；本手冊是給**現場操作人員 / 管理員 / 工程師**看的操作說明。
架構與權限規則見 `docs/功能說明書_使用手冊.md`。

## 資料夾結構

```
Manual/
├── scada/      SCADA 使用手冊（所有登入者，依頁面權限顯示章節）
├── ems/        EMS 使用手冊（同上）
├── engineer/   工程師手冊（僅 Engineer 角色）
│   ├── _toc.json        目錄：章節順序、分群、對應頁面、限定角色
│   ├── {slug}.md        各章內文（繁中）
│   ├── en/{slug}.md     英文版（選填；沒有就顯示中文並提示）
│   └── images/          渲染截圖（未來補，見下方「待補圖」）
└── README.md   本檔（不會出現在網頁上）
```

- 新增一章 = 在 `_toc.json` 加一筆 + 新增 `{slug}.md`。`_toc.json` 沒列的檔案網頁讀不到
- `slug` 只能用**小寫英數與連字號**（例 `energy-report`）
- 改完存檔即生效（開發機直接讀專案目錄；生產機要重新部署）

## _toc.json 欄位

| 欄位 | 說明 |
|------|------|
| `slug` | 章節代號 = 檔名 = URL 最後一段 |
| `title` / `titleEn` | 章節標題（英文選填） |
| `group` / `groupEn` | 左側目錄分群 |
| `routes` | 對應的功能頁路由（可多個）。登入者能進**任一頁**才看得到本章；不填 = 不綁頁面，大家都看得到。也用於從功能頁點書本圖示時直接跳到本章 |
| `roles` | 限定角色（選填），例 `["Admin","Engineer"]`。給頁面權限判不到的限制用（如帳號管理） |

> ⚠️ 一本書裡若登入者「有綁頁面且看得到」的章節一章都沒有，整本書會藏起來。

## 內文寫法

- 第一行用 `# 章節標題`，段落用 `##` / `###`（右側「本頁目錄」由 `##` `###` 自動產生）
- **操作者觀點**：怎麼進入這頁 → 畫面上有什麼 → 怎麼操作（編號步驟）→ 注意事項 / 常見狀況
- 按鈕、選單、欄位名稱用 **粗體**，且與畫面上的字**完全一致**（對照 resx 或 .cshtml）
- 選單路徑寫成：**報表查詢 → 用電報表**
- 提醒用引言：`> 💡 提示：…`、`> ⚠️ 注意：…`
- 表格可用（pipe table）；**不支援內嵌 HTML**（會被移除）
- SCADA / EMS 手冊**不寫**：類別名、SQL、資料表名、程式路徑、內部設定檔路徑。工程師手冊可寫
- 跨章連結用相對路徑：同書 `[用電報表](energy-report)`；跨書 `[趨勢圖](../scada/history)`
- 寫作者備忘可用 HTML 註解 `<!-- … -->`，網頁上不會顯示

## 待補圖（IMG-TODO）

第一版手冊只有文字。需要截圖的地方先放**獨佔一行**的標記：

```markdown
<!-- IMG-TODO: ems/energy-report-01 | 用電報表：選期別後的查詢結果表格 | route=/EnergyReport -->
```

- 格式：`IMG-TODO: {書}/{slug}-{兩位流水號} | {畫面說明} | route={要渲染的頁面}`
- 網頁上顯示為虛線灰框「待補圖：{畫面說明}」
- 全部待補清單：`grep -rn "IMG-TODO" ScadaEngine.Web/Manual`

**補圖流程（未來）**：用 `mock-render` skill 帶**假資料**離線渲染該頁（不碰生產 DB、不露出客戶點位名稱與數值）→
需要時加紅框 / ①②③ 標註對應內文步驟 → 存成 `{書}/images/{slug}-{流水號}.png` →
把該行 `IMG-TODO` 換成 `![{畫面說明}](images/{slug}-{流水號}.png)`。
圖檔只接受 png / jpg / gif / webp（不收 svg），一樣經權限檢查才輸出。
