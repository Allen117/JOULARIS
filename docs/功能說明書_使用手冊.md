# 功能說明書 — 線上使用手冊（/Manual）

## 概述

登入後點導覽列右上的**斜書本圖示**開啟使用手冊，直接在系統內閱讀操作說明。手冊分三本：

| 手冊 | 資料夾 | 誰看得到 | 主題色 |
|------|--------|---------|--------|
| SCADA 使用手冊 | `Manual/scada/` | 依登入者頁面權限顯示章節 | SCADA 深藍 |
| EMS 使用手冊 | `Manual/ems/` | 依登入者頁面權限顯示章節 | EMS 淡綠（`ViewData["EmsMode"]`） |
| 工程師手冊 | `Manual/engineer/` | **僅 Engineer 角色**（整本含圖檔） | SCADA 深藍 |

第一版**只有文字**；需要截圖處以 `IMG-TODO` 標記顯示「待補圖」虛線框，之後以 `mock-render` 渲染圖補上（見 §待補圖與補圖流程）。

內文寫作規範（給寫手）：`ScadaEngine.Web/Manual/README.md`。

## 使用方式

- **入口**：導覽列搜尋鈕右側的斜書本圖示（tooltip「使用手冊」，key `layout.manual.title`）。連結帶 `?from=目前頁面路由`：
  1. 該頁有對應章節（`_toc.json` 的 `routes`）且登入者看得到 → 直接開該章（工程師專屬頁優先找工程師手冊）
  2. 否則開該頁所屬的書（EMS 路由 → EMS、工程師頁 → 工程師、其他 → SCADA）第一章
  3. 那本也看不到 → 顯示書架 `/Manual`
- **書架** `/Manual`：列出看得到的手冊與章節數；一本都沒有時顯示「目前沒有可閱讀的手冊」
- **閱讀頁** `/Manual/{book}/{slug}`：左章節目錄（依 `group` 分群，手機收合）、中內文、右「本頁目錄」（`manual.js` 依 `h2`/`h3` 產生並隨捲動高亮，寬螢幕才顯示）；底部上一章 / 下一章；右上切換手冊、列印（`@media print` 只留內文）
- **英文介面**：讀 `{book}/en/{slug}.md`，沒有則顯示中文並提示「本章尚無英文版」；章節 / 分群標題用 `titleEn` / `groupEn`，未填退回中文

## 架構

```
Manual/{book}/_toc.json + {slug}.md      ← 內容（不放 wwwroot：靜態檔不經授權）
        │  ManualContentService（Singleton）
        │   ├ LoadToc：讀目錄、丟棄不合法 / 重複 slug；LastWriteTime 失效快取
        │   ├ GetVisibleChapters / IsBookVisible / ResolveChapter：權限（三處共用）
        │   ├ RenderChapter：Markdig（停用 raw HTML）+ IMG-TODO 提示框；同樣以 LastWriteTime 快取
        │   └ GetImagePath：圖檔名白名單
        ▼
ManualController  /Manual、/Manual/{book}、/Manual/{book}/{slug}、/Manual/{book}/images/{file}
```

| `Features/Manual/Models/ManualViewModel.cs` | 書架 / 閱讀頁 ViewModel |

## 權限規則

`PageAccessFilter` 只做路徑完全比對，擋不到 `/Manual/{book}/{slug}`，因此權限**全部在 Controller → Service** 判斷。

**章節可見** = (`roles` 未設 **或** 登入者角色在 `roles` 內) **且** (`routes` 為空 **或** 任一 route `PermissionService.CanAccessPage` 為真)

**書可見**：
- 工程師手冊：`IsEngineer(User)` 即全部章節可見，否則整本不可見
- SCADA / EMS：至少一章「**有綁 route 且可見**」。只剩不綁頁章節（快速開始、常見問題）的書不顯示

| 情境 | 結果 |
|------|------|
| 未登入 | `[Authorize]` 導登入頁 |
| 書不存在 | 404 |
| 整本看不到（不論 slug 是否存在，避免以 404 / 403 差異探出章節清單） | 導 `/Login/AccessDenied` |
| 書看得到但 slug 不合法 / 不在目錄 | 404 |
| slug 在目錄但本章看不到 | 導 `/Login/AccessDenied` |
| 圖檔：書看不到 | 403（Forbid） |

`roles` 用來補 `CanAccessPage` 判不到的限制：`/AccountSetting` 列在 `ConfigurablePages`，但 Controller 實際掛 `[Authorize(Roles = "Admin,Engineer")]`，所以帳號管理章另寫 `"roles": ["Admin","Engineer"]`，User 權限 JSON 有殘值也看不到。

Engineer / Admin 的 `CanAccessPage` 對一般頁全放行，故兩本使用手冊章節全可見；頁面權限改完需重新登入才生效（讀 Claims，與頁面權限一致）。

## _toc.json

```json
[
  { "slug": "quick-start", "title": "快速開始", "titleEn": "Quick Start", "group": "入門", "groupEn": "Getting Started" },
  { "slug": "energy-report", "title": "用電報表", "group": "報表查詢", "routes": ["/EnergyReport"] },
  { "slug": "account", "title": "帳號管理", "group": "系統設定", "routes": ["/AccountSetting"], "roles": ["Admin", "Engineer"] }
]
```

- `slug` 白名單 `^[a-z0-9][a-z0-9-]*$` 且必須列在目錄（雙重防路徑穿越）；重複者只取第一筆
- 允許註解與結尾逗號

## 內容轉換

- Markdig pipeline：`AutoIdentifiers(GitHub)`（中文標題保留為錨點）、`PipeTables`、`EmphasisExtras`、`ListExtras`、**`DisableHtml`**
- 一般 HTML 註解 `<!-- … -->` 轉換前移除（寫作者備忘）
- 相對連結以章節 URL 為基準：同書 `energy-report`、跨書 `../scada/history`、圖檔 `images/x.png` → `/Manual/{book}/images/x.png`

## 待補圖與補圖流程

標記（獨佔一行）：

```markdown
<!-- IMG-TODO: ems/energy-report-01 | 用電報表：選期別後的查詢結果表格 | route=/EnergyReport -->
```

- 轉換前先換成佔位字，轉換後換成 `<div class="manual-img-todo" data-img-id="…">待補圖：{說明}</div>`（「待補圖：」走 `Features.Manual.Controllers.ManualController.resx` 的 `manual.img_todo`）
- 待補清單：`grep -rn "IMG-TODO" ScadaEngine.Web/Manual`

**補圖（未來，另開 plan）**：
1. `mock-render` skill 帶假資料渲染 `route` 指定的頁面（不碰生產 DB、不露出客戶點位名稱與數值）
2. 需要時加紅框 / ①②③ 標註對應內文步驟
3. 存 `Manual/{book}/images/{slug}-{流水號}.png`
4. 把該行 `IMG-TODO` 換成 `![說明](images/{slug}-{流水號}.png)`

圖檔只接受 `png/jpg/jpeg/gif/webp`（不收 svg：同源 svg 可夾帶 script），檔名不得含路徑分隔或 `..`，經書本權限檢查才輸出。中英介面是否各渲染一份，補圖時再決定。

## 維護

- 改到使用者看得到的操作流程時，同步更新 `Manual/` 對應章節（root `CLAUDE.md` Documentation Rules）
- 新增功能頁：在對應手冊 `_toc.json` 加章節並填 `routes`，書本圖示才能從該頁直達
