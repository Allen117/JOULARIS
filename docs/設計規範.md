# 設計規範

本文件定義 ScadaEngine.Web 全站共用的視覺與互動規範。功能特定樣式（例如 LogicFlow 節點、能源報表圖表）若有偏離此規範的需求，請在對應功能說明書中註記原因。

新增/修改 `.cshtml`、`.css` 前先讀本檔。

---

## 框架與函式庫
- **CSS 框架**: Bootstrap 5.1.0（本地安裝）
- **圖示庫**: Font Awesome 6（`fas` 前綴）
- **圖表庫**: Chart.js + date-fns adapter
  - **全站共用預設** `wwwroot/js/common/chart-defaults.js`：新頁面引用 `chart.umd.min.js` 後**緊接著**引用此檔（再接頁面 JS），否則不吃全站預設
  - **長條寬度上限 40px**（`Chart.defaults.datasets.bar.maxBarThickness`）：柱寬預設 = 繪圖區寬 ÷ 柱數 × 0.72，柱數少時（年 12 柱、SEU 5 棟）原本會粗到 95～246px；上限只壓粗柱，31 天／24 時／並排比較等柱數多時照舊自動變細。個別圖需要不同寬度，在該 dataset 指定 `maxBarThickness` / `barThickness` 覆寫
- **語系**: zh-TW（繁體中文）

## 元件模式

### 卡片
```html
<div class="card shadow-sm">
  <div class="card-header bg-dark text-white py-2">
    <h6 class="mb-0"><i class="fas fa-[icon] me-2"></i>標題</h6>
  </div>
  <div class="card-body p-0"><!-- 表格用 p-0，表單用 p-3 --></div>
  <div class="card-footer bg-light text-muted"><!-- 統計/時間戳 --></div>
</div>
```

### 表格
- 類別: `table table-striped table-hover table-bordered`
- 表頭: `thead class="table-dark"` 或 `table-light`
- 外層: `table-responsive` wrapper
- 表頭 sticky: `position: sticky; top: 0; z-index: 30`

### 側欄（設備清單）
- 寬度: `col-md-2`
- 使用 `list-group list-group-flush`
- Active: 左邊框 3px `#0d6efd` + 背景 `#e8f0fe`
- 子項: `ps-4` 縮排 + 背景 `#f8f9fa`

#### 展開箭頭必須補齊對齊佔位（同層混排時）

側欄同一層常同時出現「有子選單」（`.coordinator-toggle`，前面有展開箭頭）與「無子選單」（`.coordinator-item`）兩種項目。
**無子選單的那一種必須補一個與箭頭同寬的隱形佔位**，否則它的圖示與名稱會比有箭頭的項目左移一格：

```html
<i class="fas fa-chevron-right me-1" style="font-size:.7rem;visibility:hidden;"></i>
```

用 `visibility:hidden` 而非 `display:none` —— 前者保留佔位寬度，後者不佔空間等於沒補。

> 適用對象是**左側展開箭頭**。picker 那種「左圖示 + 名稱(flex:1) + 右箭頭」的欄位式清單，
> 兩種項目右端都有箭頭、名稱左緣本來就齊，不需要也不應該補佔位。
> 同理，整份清單都沒有子選單的頁面（如 `/DbCoordinator`）不需補，補了只會讓全清單無故右移。

### 按鈕
- 頁面內主要動作（儲存 / 刪除 / 確認 / 匯入匯出等 `btn-primary` / `btn-danger`）: `<i class="fas fa-[icon]"></i> 文字`（圖示+文字）— 動作有後果，不靠猜
- 頂端列 / 工具列 / 表格列操作 / 卡片角落的小按鈕: **只放圖示 + `title` tooltip**，不加文字 → 見 §圖示慣例「圖示優先、文字進 tooltip」
- Hover: `translateY(-1px)` 上浮
- Active: `translateY(1px)` 下壓

### 表單
- 標籤: `form-label fw-semibold` + 前置圖示
- 輸入: `form-control form-control-sm`
- 下拉: `form-select form-select-sm`
- 排列: `row g-3` + `col-md-*`

### Modal
- 標準結構: `.modal-header` + `.modal-body` + `.modal-footer`
- 取消: `btn btn-secondary`（左）、確認: `btn btn-primary`（右）

### 空狀態
```html
<div class="text-center text-muted py-4">
  <i class="fas fa-inbox fa-3x mb-2 d-block"></i>
  <div>尚無資料</div>
</div>
```

### 時間輸入（24 小時制，用 flatpickr）

**新增**任何 datetime / time 選擇控制項時**禁止**用原生 `<input type="datetime-local">` / `<input type="time">`：Chromium 在 zh-TW Windows 下會強制吃 OS locale 顯示「下午 01:34」，`lang="en-GB"` trick 對 datetime-local 已證實無效。改用 flatpickr + 共用 helper `window._fpInit`。

date-only（純日期、無時間）可繼續用原生 `<input type="date">` — 無 AM/PM 問題不必引入 flatpickr。**例外：允許留白的日期欄位**（如空壓機診斷設定的劣化基準期）空值時 zh-TW Chromium 會露出「yyyy/月/dd」中英混雜佔位，改用 `window._fpInit.date(el)`（`Y-m-d`）+ `placeholder="YYYY-MM-DD"`。

```html
<!-- View 頂端 -->
<link rel="stylesheet" href="~/lib/flatpickr/flatpickr.min.css" />

<!-- input 用 type="text" -->
<input type="text" id="dtStart" class="form-control" autocomplete="off" />

<!-- @section Scripts 依序載入 -->
<script src="~/lib/flatpickr/flatpickr.min.js"></script>
<script src="~/lib/flatpickr/zh-tw.js"></script>
<script src="~/js/flatpickr-init.js"></script>
<script src="~/js/myfeature.js"></script>
```

```js
// feature.js 內初始化（依 <html lang> 自動切 zh-TW / en locale，強制 time_24hr）
window._fpInit.datetime(document.getElementById('dtStart'));  // YYYY-MM-DD HH:mm
window._fpInit.time(document.getElementById('txtStartTime'));  // HH:mm

// 寫值要走 setDate，不能直接 .value = ...（picker 狀態不會同步）
dtStart._flatpickr.setDate(new Date(), true);
// 讀值照舊用 .value
var s = dtStart.value;
```

Razor 預設值輸出空白分隔格式對齊 flatpickr `Y-m-d H:i`：`Model.dt.ToString("yyyy-MM-dd HH:mm")`。後端 `DateTime.TryParse` 對 T / 空白分隔都吃，不需改 API。

#### 滾輪調值（全站共用 `js/common/date-wheel.js`，_Layout 已載入，各頁不必再引）

所有日期 / 時間輸入都能用滑鼠滾輪調值，事件委派在 `document`，JS 動態產生的輸入框（期別表格列、電價生效日等）一樣吃得到：

| 目標 | 滾輪效果 |
|------|---------|
| 原生 `<input type="date">` | ±1 天 |
| 原生 `<input type="month">` | ±1 月 |
| flatpickr datetime 文字框 | ±1 天 |
| flatpickr time 文字框（noCalendar） | ±`minuteIncrement` 分 |
| flatpickr 面板：日曆格 / 月份列 | 換月（**向下 = 下個月**，捲時間軸直覺） |
| flatpickr 面板：年 / 時 / 分數字框 | ±1（派發 flatpickr 自己的 `increment` 事件，分→時進位、24h 迴繞照它的規則） |

- **方向**：數字框 / 輸入框「向上 = 往後（+）」，與欄位旁 ▲▼ 箭頭一致（Chromium number input 慣例）；只有日曆格換月反過來
- **安全閥**：輸入框本身**必須已取得焦點**（先點一下再滾），游標只是掃過時照常捲頁面，不會捲到一半把日期改掉；flatpickr 面板上一律攔下；Ctrl + 滾輪（縮放）不攔；觸控板小幅 deltaY 累積到門檻才動一格
- **相容**：改值後派發 `input` + `change`（bubbles），各頁既有 `change` 監聽照常觸發；flatpickr 走 `setDate(d, true)` 觸發 onChange；尊重 `min` / `max`（超界不動）；空白框從今天 / 本月起算
- 新頁面**不需**做任何事即自動支援；若某輸入框刻意不要滾輪，設 `readonly` 或不給焦點即可

## 色彩系統

### SCADA / EMS 雙主題

全站依路由分為兩套色系。`_Layout.cshtml` 偵測 `PermissionService.IsEmsRoute()` 自動掛 `body.ems-mode` class；`ems.css` 在該 class 下覆寫 navbar / footer / brand 與所有 Bootstrap primary 衍生 class（`.text-primary` / `.btn-primary` / `.bg-primary` / `.form-control:focus` / `.spinner-border.text-primary` / `.card-header.bg-primary`），以及樹狀清單 `#treeContainer .tree-node.active` 等共用元件。

**頁面寫法**：直接用 Bootstrap class，不要硬寫色號，色系切換交給 `ems.css` 自動處理。新增 EMS 子頁專屬色彩時用 `body.ems-mode .your-class` 覆寫，避免污染 SCADA 模式。**不要在 `.cshtml` inline 硬寫藍色色號（如 `style="color:#0d6efd"`），會破壞 EMS 模式切換。**

**新增 EMS 子頁掛載步驟**（自動套主題，不需在 View / Controller 手動切色）：

1. 路由加入 `PermissionService.EmsRoutes[]`（同時加 `ConfigurablePages` 給權限管理用）
2. `_Layout.cshtml` 偵測 `IsEmsRoute()` 自動掛 `body.ems-mode` class（既有機制，不用改）
3. `ems.css` 自動把 navbar / brand / footer 綠色化 + 覆寫 Bootstrap primary 衍生 class（見上）
4. navbar 加 nav-link（搭 i18n key `layout.menu.xxx`，走 `Views.Shared._Layout.{,en}.resx`）

### 圖示優先、文字進 tooltip（版面清晰原則，2026-10-17 起）

**能用圖示就不要圖示 + 文字**；文字放 `title`（滑鼠停留 tooltip）與 `aria-label`（無障礙），版面只留圖示與必要的數字徽章。

- **適用**：頂端列 nav 項（鈴鐺、搜尋、語系）、頁面工具列、表格每列的編輯 / 刪除 / 排序按鈕、卡片右上角的刷新 / 展開
- **數字要跟著圖示**：筆數、剩餘分鐘等狀態一律做成圖示旁的小徽章（`.as-count` 這種圓角 badge），不寫成「剩 15 分鐘」句子 — 例：警報鈴鐺 🔔 + 紅色筆數、🔕 + 灰色剩餘分鐘
- **例外（仍保留文字）**：① 頁面內主要動作按鈕（儲存 / 刪除 / 確認 / 匯入）— 有後果的動作不靠猜；② glyph 語意不唯一的操作（同一列有兩個以上「設定類」圖示）；③ 下拉選單**內**的項目 — 選單本身就是展開看文字的地方，圖示 + 文字照舊
- **tooltip 是硬性要求**：icon-only 元素**必須**帶 `title` + `aria-label`（Localizer 字串），兩者缺一即視為未完成
- 既有「圖示 + 文字」的頂端列 / 工具列元素，改到時順手收成 icon-only，不另開 commit 全站翻修


**① 頁面標題圖示 = 該頁側欄選單的圖示**
`<h2>` 的圖示要與 `_Layout` 裡對應選單項用同一個 glyph，使用者才對得起來。
⚠️ 複製既有頁面當範本時**最容易漏改這一行** — 例：水表 / 氣表迴路設定曾整頁沿用電表的 `fa-sitemap`。
`fa-sitemap` 專指**電表**迴路設定（`/EnergyMeter`），水表用 `fa-faucet`、氣表用 `fa-gas-pump`。

**② 同一個下拉選單內不得出現重複 glyph**
`_Layout` 的「報表」「設定」兩個 dropdown（含各 submenu 群組標頭）各自不可撞號，
否則使用者在同一張清單上看到兩個一樣的符號無法區辨。新增選單項時先掃一遍該選單既有圖示。

### 符號屬於元件、不屬於文案（2026-10-17 起）

畫面上**禁用 emoji / 字元符號**（⚠ ▲ ▼ ● ○ ⚡ ✕ 🤖 📊 👍 📁 等）當圖示；需要圖示的地方一律用 Font Awesome，且圖示由**元件**提供，不寫進 resx 文案。
2026-10-17 盤點 14 種 / 78 處後依下列四條判準清理，多數直接移除、僅 4 組換成 FA：

1. **圖示屬於元件，不屬於文案**：resx / 字串只負責語言，警告三角由警告容器（chip / badge / alert / `UiState` helper）提供一次。否則同一個 ⚠ 要在 20 幾支 resx 兩種語言各維護一份。
2. **一個狀態編碼 1～2 次就夠**：色彩 + 文字已是兩次，再加符號是第三次雜訊（例：綠底「ON」pill 不再加 ●；AI 幫手判定句改氣泡左側色條，不加 👍 / ⚠）。
3. **符號不得與全站圖示語彙衝突**：`fa-bolt` ⚡ 固定代表「電」，LogicFlow 的 C# 演算法改文字 chip `.ui-lang-tag`「C#」。
4. **警告要有層級**：表格單格的資料品質標記（`*-stale-mark`，小而安靜）與卡片標頭的區塊警告（`.ui-warn-text`，琥珀色）是兩種東西；區塊警告不可用 `text-muted` 灰字。

**共用 helper `js/common/ui-state.js`（`window.UiState`，_Layout 於 i18n.js 之後全站載入）+ `css/ui-state.css`**：

| 用途 | 呼叫 | 產出 |
|------|------|------|
| 區塊警告（卡片標頭 / 面板） | `UiState.setWarnText(elOrId, text)` | DOM 版：`fa-exclamation-triangle` + 文字節點；text 為空 → 清空並 `hidden`。容器加 `class="ui-warn-text small" hidden` |
| 模板字串內的警告 | `UiState.warnHtml(text)` | 圖示 + 已跳脫文字；空字串回空 |
| 表格單格 stale 標記 | `UiState.staleMarkHtml(cls, tip)` | ` <span class="cls" title="tip"><i class="fas fa-exclamation-triangle"></i></span>`，色彩由各頁 `.xx-stale-mark` 給 |
| 年增減百分比 | `UiState.pctHtml(p, upCls, downCls)` | 正 → `fa-caret-up` + `+x.x%`、負 → `fa-caret-down`、0 → 灰 `0.0%`、null → `--` |

**4 組保留圖示的對應**：警告三角 `fa-exclamation-triangle`、樹展開 `fa-chevron-down`（收合用既有 rotate）、刪除 / 移除 `fa-times`（計算點測試失敗 `fa-times-circle`）、LogicFlow 歷史值 badge `fa-history`。

**純文字容器放不了圖示時**（`<option>` / `confirm()` / Excel / Line）：
- 報表迴路下拉：實體表加字尾 resx `*.circuit.meter_tag`「（表）」/ " (meter)"（冷凍噸「（點位）」/ " (point)"），群組無字尾、靠縮排 `└` 辨識
- `confirm()` 文案：⚠ 改「注意：」/ "Note: "
- Excel 警告列：去 ⚠，紅字樣式（`XLColor.Red`）照舊
- Line / Email 通知字串**例外保留 emoji** — Line 純文字唯一圖示手段就是 emoji，Email 各信件軟體對 inline SVG 支援不一

### 下拉選單圖示對齊（已由 CSS 統一處理，不需逐項加 class）

Font Awesome 是字型圖示，各字符 advance width 本來就不同（`fa-tint` 窄、`fa-file-invoice-dollar` 寬），
直接排在文字前會讓每列文字左緣參差。`wwwroot/css/navbar-submenu.css` 已對
`.navbar .dropdown-menu .dropdown-item > .fas`（含 submenu 群組標頭）統一
`width: 1.25em` + `text-align: center` + `font-size: 1em`（等同 FA 的 `.fa-fw`）。

→ 新增選單項照現有寫法 `<i class="fas fa-xxx me-2">` 即可，**不必也不要**額外加 `fa-fw` / `fa-lg` / `fa-sm`
（`font-size: 1em` 會把 `fa-lg`、`fa-sm` 壓回去，避免有人單獨放大某一項造成大小不一）。

### 下拉選單寬度與 submenu 箭頭（同檔 CSS，勿改回 float）

- `.navbar .dropdown-menu` 設 `min-width: 13rem` —— Bootstrap 預設 10rem，中文標籤（「空調水系統」「卡片顯示設定」）
  加上固定寬圖示後幾乎貼滿，各列會擠成一團。比 13rem 長的標籤仍會自動撐開。
- submenu 群組標頭的展開箭頭 `::after` 用**絕對定位**貼右緣，**不可改回 `float: right`**：
  float 的箭頭是流內元素，內容剛好填滿 content box 時會整個掉到下一行，看起來像箭頭疊在文字底下
  （中文標籤與切英文後的長標籤都會踩到）。
- **箭頭一律朝下**（沿用 Bootstrap 預設 caret 形狀，只做 `translateY(-50%)` 垂直置中，**不旋轉**），
  與上方主列的下拉箭頭一致 —— 讀者看到的訊息是「這一項還能展開」，不是「往哪個方向飛出」。
  子選單雖是橫向 flyout，且右側空間不足時 `navbar-submenu.js` 會加 `.submenu-flip` 翻向左開，
  **`.submenu-flip` 只改展開位置、不動箭頭**（否則同一張清單裡各指各的方向）。

### submenu 的開合：桌機 hover、觸控 click，`.show` 由 `mouseleave` 負責收

桌機展開靠 CSS `:hover`；`.show` class 只是為了讓沒有 hover 的觸控/小螢幕也能點開。
兩套機制並存時，**click 掛上的 `.show` 必須在 `mouseleave` 時移除**（`navbar-submenu.js`，
桌機才做，小螢幕內嵌展開不適用），否則點開過的子選單會一路留著 ——
滑到同一張選單的其他群組時，舊子選單仍展開並與新的疊在一起。
同理 `mouseenter` 時先 `closeAll(item)` 收掉別人。
子選單 `<ul>` 是父項 `<li>` 的子元素，滑進子選單不會觸發父項 `mouseleave`，不影響操作。

⚠️ **樣式與行為只能有一份**：`_Layout.cshtml` 曾另有一份 inline `<style>` + `<script>` 複本，
排在外部檔之後、選擇器多一個 `a`（特異性較高），造成兩個難查的症狀 ——
(1) 改 `navbar-submenu.css` 完全不生效，箭頭被 inline 的「朝右三角」蓋掉、再被外部的 `rotate(-90deg)`
轉成**朝上**；(2) 兩份 JS 各掛一個 click 監聽、各 `toggle('show')` 一次互相抵銷，觸控點擊展不開子選單。
新增樣式/行為請一律回到 `wwwroot/css/navbar-submenu.css` 與 `wwwroot/js/navbar-submenu.js`。
