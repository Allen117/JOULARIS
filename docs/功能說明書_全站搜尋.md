# 功能說明書 — 全站搜尋（Ctrl+K 命令面板）

## 概述

導覽列右側的全站搜尋視窗，輸入頁面名稱（zh-TW / en / 同義關鍵字皆可）即列出可前往的頁面超連結。
純腳本比對，無 LLM、無外部依賴；索引在伺服器端依登入者權限過濾後才下發。

## 使用方式

- **開啟**：導覽列搜尋鈕，或快捷鍵 `Ctrl+K`（macOS `Cmd+K`）。導覽列搜尋鈕只顯示放大鏡圖示，說明走 tooltip（`layout.search.title`），不另標文字或 `Ctrl K` 鍵帽提示（快捷鍵仍有效）
- **操作**：輸入即比對；`↑` `↓` 選擇、`Enter` 前往、`Esc` 關閉
- **空字串**：只顯示「最近使用」（依最後點擊時間排序）；尚無使用紀錄則留白，不預先列出選項
- **跨語系**：zh-TW 介面下輸入 `report` 一樣命中各報表頁（索引每筆同時攜帶雙語標題）
- EMS 體系頁面於結果列附綠葉標記

## 架構

```
GET /api/globalsearch/index   ← [Authorize]，依登入者權限過濾（CanAccessPage）
        │  { entries: [{ szRoute, szTitleZh, szTitleEn, szKeywords, szIcon, isEms }] }
        ▼
wwwroot/js/global-search.js   ← 前端本地比對 + 排序 + 渲染（IIFE，window._globalSearch）
```

| 檔案 | 職責 |
|------|------|
| `Services/GlobalSearchService.cs` | **頁面註冊表（唯一真相來源）**：路由 + `_Layout` resx key + 圖示 + 同義關鍵字。標題經 `I18nResourceService` 同時取 zh-TW / en 兩份字典；逐筆走 `PermissionService.CanAccessPage` 過濾。Singleton |
| `Features/GlobalSearch/Controllers/GlobalSearchController.cs` | `GET /api/globalsearch/index`，回應標頭 `Cache-Control: private, max-age=300` |
| `Features/GlobalSearch/Models/SearchIndexEntry.cs` | 索引條目 DTO |
| `wwwroot/js/global-search.js` | 比對計分、頻率記錄、鍵盤操作、渲染 |
| `wwwroot/css/global-search.css` | Modal 樣式（主色走 Bootstrap class，EMS 主題自動轉綠） |
| `Views/Shared/_Layout.cshtml` | 導覽列搜尋鈕 + Modal 標記 + JS/CSS 引用（皆包在已登入判斷內） |

## 比對與排序規則

分數 = 各欄位最佳比對分 + 使用頻率加權：

| 比對 | 分數 |
|------|------|
| 標題（zh 或 en）前綴 / 子字串 / 子序列 | 100 / 70 / 35 |
| 路由（去掉 `/`）同規則 | 上限 80 |
| 同義關鍵字同規則 | 上限 60 |
| 英文標題字首縮寫前綴（`er` → Energy Report） | 90 |
| 頻率加權 | `min(點擊次數, 20) × 3` |

- 子序列比對：輸入 `wtr` 可命中 `water`（模糊容錯，query ≥ 2 字元才啟用）
- 縮寫比對限純英文 query ≥ 2 字元；字首推不出的縮寫（如 `pm` = Power Meter）於註冊表關鍵字手動補
- 命中子字串時標題以 `<mark>` 高亮
- 結果不顯示路由，僅圖示 + 標題（EMS 頁附綠葉標記）
- 取前 12 筆

## 使用頻率

存於 `localStorage`（key `scadaGlobalSearchFreq`，格式 `{ route: { n: 次數, t: 最後點擊 ms } }`），
不進 DB — 換裝置/清瀏覽器資料歸零屬可接受行為（僅影響排序微調）。

## 權限

- 索引**在伺服器端過濾完才回傳**，前端拿不到無權限頁面的存在資訊（DevTools 也看不到）
- 工程師專屬頁（Designer、各 Coordinator、LogicFlow…）僅 Engineer 角色的索引會包含
- 未登入：導覽列不渲染搜尋鈕與 Modal，API 亦擋 `[Authorize]`

## 新增頁面時怎麼讓它可被搜尋

`GlobalSearchService._registry` 補一筆（路由、`_Layout` resx key、圖示、同義關鍵字）即可；
resx key 需 zh-TW / en 同步存在（本來就是選單 i18n 的要求）。

## i18n

搜尋視窗字串走 `Views.Shared._Layout.{,en}.resx`，key 前綴 `layout.search.*`；
JS 端訊息（無結果、最近使用、錯誤）走 `window.i18n.t`。

## 刻意不做（v1 範圍）

- **不索引 DB 內容**（點位名、迴路名）— 屬第二階段，牽涉查詢與資料權限
- **無逐字打字動畫** — 搜尋以速度優先，結果即時呈現
- **頻率不進 DB** — 見上節
