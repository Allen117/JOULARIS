# 功能說明書 — 能源日報

每日 **02:00** 自動整理**前一日**全廠營運概況成一份日報：警報摘要、電/水/氣/冷凍噸時報表、單日與月累計比較、規則式智慧提示，存成 DB 快照並依設定寄送 HTML Email。管理者早上打開信箱即可掌握昨日全廠能耗與異常，不必逐頁點報表。

- 瀏覽頁：`/DailyReport`（EMS 主題，導覽列頂層「能源日報」，位於「報表查詢」與「能源基準」之間）
- 設定頁：`/DailyReportSetting`（EMS「能管設定」→「設定」子選單；亦可從日報頁右上「日報設定」進入）

---

## 1. 日報內容（區塊）

| 區塊 | 內容 | 無資料時 |
|------|------|---------|
| 警報摘要 | 前一日 EventLog **警報 + 故障（EventType 0+1）**：發生/已恢復/未確認統計 + 明細。Web 頁預設收合前 20 筆、按「展開全部」看全部；Email 僅列前 20 筆 + 「其餘 N 筆請至系統查看」 | 顯示「無警報/故障事件」 |
| 用電時報表 | 24 小時 bar（kWh）+ 日總量 | 未設定電表迴路 → 區塊隱藏 |
| 用水時報表 | 24 小時 bar（m³）+ 日總量 | 未設定自來水表迴路 → 隱藏 |
| 用氣時報表 | 24 小時 bar（m³）+ 日總量 | 未設定氣表迴路 → 隱藏 |
| 冷凍噸時報表 | 24 小時 bar（RT·h）+ 日總量 | 未設定 WaterCircuit → 隱藏 |
| 單日比較 | 各能源別：報告日 vs **前日（D-1）** vs **上週同星期（D-7）**，總量 + 差異%；含 **kWh/RTh** 每冷凍噸耗電比值列（無 RTh 時隱藏）；報告日與 D-7 的假日/上班日狀態不同時附**比較基準備註**（見下）；下方附外氣日均溫（有設定氣象來源時） |
| 月累計比較 | **本月 1 日～報告日累計** vs **去年同月 1 日～同日數**（MTD 年同期；去年 2 月遇 2/29 邊界取 min(日數, 當月天數)） |
| 智慧摘要 | 規則式提示（見 §3），**不串接 LLM API** |

**比較口徑**：各能源別「**根迴路合計**」（樹根節點；多 root 時加總）。逐迴路明細留給既有各報表頁。

**徽章**：報告日為假日 → 假日徽章（可整體停用）；報告日 23 時缺資料 → 「最後時段資料缺漏」；該日期無 02:00 快照（Web 即時計算）→ 「即時計算」；有快照時顯示 Email 寄送狀態。

**vs 上週同星期的比較基準備註**：報告日與 D-7 的**假日/上班日狀態不同**時（`isReportDateHoliday != isLastWeekHoliday`），單日比較表下方顯示備註標明兩者基準不同、差異僅供參考。同一個星期幾本來就同為平日或同為週末，狀態不同必然來自**國定假日或補班日**。兩者狀態相同（例如連假期間都放假）不顯示 —— 基準一致時提示只是噪音。Web 頁與 Email 同步顯示，判定集中在 `DailyReportInsightService.LastWeekBaselineShift`（靜態純函式）避免三處漂移。

**數值顯示位數**：kWh 與 RT·h 一律**小數一位**（0 顯示為 `0.0`），用水 / 用氣最多兩位，kWh/RTh 效率比值三位。**計算與快照存的是全精度**，只有顯示端收斂 —— 否則葉子加總會 ≠ 父節點總計。

## 2. 快照機制

- 02:00 生成後整份 `DailyReportData` 序列化 JSON 存 **`DailyReportSnapshot`**（一天一列，UPSERT by ReportDate）
- **Email 與 Web 頁讀同一份快照** — 歷史日報不受後續資料回補影響；也是「已寄過」的冪等依據（MailStatus：0 未寄 / 1 成功 / 2 失敗 / 3 停用）
- 快照**永遠存全部區塊**，`SectionFlags` 在顯示端（Web 頁 + Email 組版）過濾 → 改設定即時生效、不需重生成
- Web 選到**沒有快照**的日期 → 即時計算（不落 DB），頁面標「即時計算」徽章；僅接受昨日（含）以前的日期
- **catch-up**：Web 啟動時最近 N 天（appsettings `DailyReport:CatchUpDays`，預設 3）缺快照自動補生成 — **補生成不補寄**（避免當機後隔天連發舊信）。「昨日」由主迴圈處理：重啟後漏跑的 02:00 當天仍會生成 + 寄送
- 02:00 觸發點在 Engine 水/氣 Hourly 聚合（XX:03，00:03 完成前一日 23 時）之後，資料完整；生成時仍檢查最後一小時，缺則標 stale

## 3. 智慧摘要（規則式）

`DailyReportInsightService` 確定性規則，零外部依賴（使用者定案不串接 API）。門檻 = 設定頁「差異提示門檻」（預設 ±15%）：

| 規則 | 觸發條件 | 範例文案 |
|------|---------|---------|
| 假日效應 | 報告日 / 前日在 `Holidays` 表；**上週同星期只在與報告日狀態不同時**觸發（**情境提醒，不看門檻**；`IsHolidayHintEnabled=0` 整類跳過） | 「比較基準不同：報告日為上班日、上週同星期為假日，vs 上週同星期比較僅供參考」 |
| 天氣差異 | 某基準日能源差異超門檻 **且** 與該基準日外氣日均溫差 > 3°C（Weather S1 日均，未設定 CWA 自動停用） | 「報告日均溫 33.2°C，較上週同星期高 4.1°C，空調負載增加為可能原因」 |
| 警報關聯 | 某能源 vs 前日超門檻 且 當日有警報/故障（取差異最大的能源別） | 「用電較前日增加 18.2%，當日發生 3 筆警報/故障事件，可能相關」 |
| 效率異常 | kWh/RTh 比值偏離基準日 > 門檻（取偏離較大的基準） | 「單位冷凍噸耗電上升，主機效率或負載率變化為可能原因」 |
| 中性 fallback | 有超門檻差異但無任何原因類提示命中 | 「差異原因無明確線索，建議查看時趨勢圖進一步分析」 |

文案模板進 resx（`Resources/Services.DailyReportInsightService.{,en}.resx`），依全局語言於生成時渲染進快照。規則判定為靜態純函式 `EvaluateRules`，單元測試在 `ScadaEngine.Tests/DailyReport/`。

## 4. Email 寄送

- SMTP 連線**沿用警報通知的 `EmailSetting.json`**（經 `EmailSenderConfigService`，生產機 `C:\SCADA\Shared\EmailSetting.json`、與 Engine 同一份，見 [架構.md §共用設定檔解析順序](架構.md#共用設定檔解析順序)），不另設一份；但**不看** `EnableNotification`（那是警報總開關）— 日報有自己的 `IsMailEnabled`
- 收件清單獨立表 **`DailyReportRecipients`**（訂閱名單語意，不掛警報 EmailGroups）
- `DailyReportHtmlBuilder` 產 **inline-style HTML**（table 排版；長條圖用純 HTML/CSS div 高度，不產圖片、不引外部 CSS/JS）
- 逐收件人寄送（單一 SMTP 連線重用），結果寫 **EventLog**（EventType=3、NotifyChannel='Email'、NotifyStatus/NotifyDetail，格式同 Engine `NotifyDeliveryLogger`）
- 冪等：MailStatus=1（成功）/ 3（停用）不重寄；=2（失敗）不自動重試，可用「測試寄送」手動補
- **測試寄送**：設定頁按鈕 → 立即以「昨日」內容（快照優先）寄給所有啟用收件人，主旨帶【測試】，全域 throttle（`TestSendThrottleSeconds`，預設 10 秒），不改快照 MailStatus

## 5. 設定頁

| 設定 | 說明 |
|------|------|
| 每日自動寄送 | 關閉時快照照常生成（MailStatus=3），只是不寄 |
| 日報語言 | zh-TW / en **全局單選** — 提示文字與警報訊息以此語言渲染進快照 |
| 差異提示門檻 | ±%（預設 15，1–100） |
| 假日提示 | 停用後假日徽章與假日類智慧提示皆不出現（24 小時生產場域適用） |
| 內容區塊 | 8 個 bitmask 勾選（警報/電/水/氣/RTh/單日比較/月累計/提示）；未設定迴路的能源別勾了也會自動隱藏 |
| 收件人清單 | Email + 顯示名稱 + 啟用開關，逐筆增刪 |

## 6. 資料表

| Table | 用途 |
|-------|------|
| `DailyReportSnapshot` | ReportDate (UNIQUE) + PayloadJson + MailStatus/MailDetail — 每日快照與寄送冪等 |
| `DailyReportSetting` | 單列 Id=1 — IsMailEnabled / SectionFlags / DiffThresholdPercent / Language / IsHolidayHintEnabled |
| `DailyReportRecipients` | 收件人（獨立於警報 EmailRecipients） |

欄位定義唯一真相來源：`ScadaEngine.Engine/DatabaseSchema/DatabaseSchema.json`（Engine/Web 啟動自動建表）。
