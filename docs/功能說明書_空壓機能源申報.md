# 功能說明書：空壓機能源申報

## 1. 功能概述

EMS（能源管理）體系子頁 `/AirCompressorDeclaration`，與冰水系統的 [能源申報](功能說明書_能源申報.md) **同構**，
只把第二來源從「空調水系統迴路（RT·h）」換成「產氣量表迴路（Nm³）」：

1. 使用者建立多份申報報表設定（如「空壓一廠」），每份**成對**綁定：
   - **用電度數來源**：一個 `EnergyCircuit` 迴路節點（kWh，葉子或虛擬皆可）— 與冰水申報同一棵電表樹
   - **產氣量來源**：一個 `AirMeterCircuit` 迴路節點（Nm³，葉子或虛擬皆可）→ [功能說明書_產氣量表.md](功能說明書_產氣量表.md)
2. **查詢格式固定**：選報表 + 申報年度 → 該年 **12 個曆月**（每月 1 號 00:00 ~ 次月 1 號），每月三欄：
   - 用電量 (kWh)
   - 產氣量 (Nm³)
   - **比能耗 (kWh/Nm³)** = kWh ÷ Nm³（Nm³ ≤ 0 時顯示 `--`）
3. 雙軸圖（kWh 長條 + Nm³ 折線，tooltip footer 顯示該月比能耗）+ 明細表 + 匯出 Excel（ClosedXML）

### 核心設計原則（第一性原理）

申報頁本身只是「兩條曆月序列依 index 對齊相除」，計算層不重寫：

- kWh 委派 `EnergyReportService.GetCalendarMonthlyReportAsync(circuitId, year)` —
  **與冰水申報同一支**，同用電迴路、同年度的 kWh 必然與 `/EnergyDeclaration` 完全一致
- Nm³ 委派 `AirMeterUsageReportService.GetCalendarMonthlyReportAsync(circuitId, year)`（讀 `AirMeterLeafHourly` 預聚合）
- 兩側都用 `EnergyReportService.BuildCalendarMonthRanges(year)` 切界 → 12 個 bucket 依 index 合併；
  合併為純函式 `AirCompressorDeclarationService.Merge`（bucket 數不一致即擲 `bucket_mismatch`）

**效率指標只做比能耗 kWh/Nm³**（使用者決策，2026-10-15）；比功率 kW/(Nm³/min) 不顯示。

## 4. 資料表 `AirCompressorDeclarationReport`

| 欄位 | 型別 | 說明 |
|---|---|---|
| Id | int identity PK | |
| Name | nvarchar(100) | 報表名稱 |
| EnergyCircuitId | int NOT NULL | 用電來源 — EnergyCircuit.Id（應用層參照，無 DB FK） |
| AirMeterCircuitId | int NOT NULL | 產氣量來源 — AirMeterCircuit.Id（必填，與用電成對） |
| SortOrder | int default 0 | 新增時自動 MAX+1 |
| Description | nvarchar(500) NULL | |
| CreatedAt / UpdatedAt | datetime | |

**刻意不與 `EnergyDeclarationReport` 共表**（不加 Kind 欄）：冰水表的 `WaterCircuitId NOT NULL` 需放寬才能共用，
且共用一頁會讓兩種單位混在同一張設定表、權限也無法分開。專案慣例是平行體系各自獨立。

**來源被刪除時**：設定列不級聯刪除；清單紅字「來源已不存在」，查詢回 `energy_circuit_missing` / `air_circuit_missing`。

## 5. 合併查詢流程（GetDeclarationReportAsync(reportId, year)）

1. 年度範圍檢查（2000~2100）、讀取設定列
2. kWh：`EnergyReportService.GetCalendarMonthlyReportAsync(EnergyCircuitId, year)`
3. Nm³：`AirMeterUsageReportService.GetCalendarMonthlyReportAsync(AirMeterCircuitId, year)`
4. `Merge`：檢查 bucket 數一致 → 依 index 合併，逐月 `dKwhPerNm3 = Round(kWh / Nm³, 3)`，Nm³ ≤ 0 → null
5. 整體比能耗 `dTotalKwhPerNm3 = 總 kWh ÷ 總 Nm³`（**加權值，不是各月比能耗的平均**；總 Nm³ ≤ 0 → null）
6. 兩側警告獨立：`isHasKwhWarning`（電表缺資料 / 溢位無 MaxKwh）、`isHasNm3Warning`（產氣量表有掉線 transition）；
   逐月另帶 `isKwhStale` / `isNm3Stale`，表格與 tooltip 以 ⚠ 標示

## 6. 權限 / EMS 整合

- `PermissionService.ConfigurablePages` 加 `("/AirCompressorDeclaration", "空壓機能源申報")` → 帳號管理**單獨**配置（不與冰水申報共用）
- `PermissionService.EmsRoutes` 加 `/AirCompressorDeclaration` → 套 EMS 綠色主題
- `_Layout.cshtml` EMS「報表查詢」下拉，排在「能源申報」下一列（icon `fa-wind`，`layout.menu.air_compressor_declaration`）
- ⚠️ `canAccess("/EnergyDeclaration")` 同時守門 AI 智慧幫手；本頁權限獨立，**未動**該判斷
- 全站搜尋（Ctrl+K）已收錄

## 7. UI 操作步驟

1. 先到 EMS 設定 → 產氣量表 → 產氣量表/迴路設定，建立產氣量表迴路（多台空壓機用虛擬迴路加總）
2. EMS 導覽列 → 報表查詢 → 空壓機能源申報
3. 「申報報表設定」→ 新增報表 → 填名稱、選用電迴路、選產氣量表迴路（兩者必填）→ 儲存
4. 「查詢條件」選申報報表 + 年度（預設今年）→ 查詢，固定產出 1~12 月
5. 左圖右表；footer 顯示總用電 / 總產氣 / 整體比能耗
6. 「匯出 Excel」：報表名稱 / 用電迴路 / 產氣量來源 / 申報年度 / 查詢時間 / 操作者 + 四欄 12 列 + 合計列

## 8. 顯示規則

- kWh 與 Nm³ 小數一位帶千分位（Excel `#,##0.0`）；比能耗三位（Excel `#,##0.000`）
- 分母 ≤ 0 → `--`
- DB 內容（報表名稱、迴路名）為使用者輸入，不在 i18n 範圍

## 9. 已知限制

- 查詢格式固定：只選年度、固定 12 曆月（申報用途）
- Nm³ 預聚合延遲：產氣量表在 XX:04 聚合上一小時，當月（進行中）數字可能偏低
- 比能耗不做溫壓修正、不做比功率
